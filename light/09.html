흐름 설계 메모

계획안 한 권 = 퀘스트 한 장(章). 핵심 과제는 메인 퀘스트, 연계 과제는 서브 퀘스트, 기대 효과는 보상 아이템이다.

계획안 구성게임 화면 요소안쪽 장표 레이아웃 아이디어
표지퀘스트 일지 전체 화면지금 표지 그대로. 상태 바에 기관·보고일, 커서가 올라간 장(章) 이름이 계획 제목이다.
Ⅰ. 추진 배경의뢰인 대화창 (초상화·이름표·▼)화면 아래 1/3은 대화창, 위는 '마을 게시판' 창에 돌봄 수요 지표 2~3줄. ▼ 한 번에 근거 한 문장씩 넘긴다.
Ⅱ. 목적·방침퀘스트 수락 창 (목표 체크박스 + 수락/거절)가운데 큰 창 하나. 목적 한 줄이 퀘스트 이름, 방침 3개가 빈 체크박스. 마지막에 A 수락 버튼이 눌리며 다음 장으로.
Ⅲ. 세부 추진 과제★ 메인핵심 과제 ◆ 서브연계 과제 + 상세 창왼쪽 목록 창은 매 장 고정, 커서만 한 칸씩 내려간다. 오른쪽 상세 창에 과제별 세부 목표(0/3)와 담당 부서를 '파티원' 칸으로 넣는다.
Ⅳ. 추진 일정진행 단계 트래커 (노드 + 연결선)장표를 가로지르는 큰 트래커 4칸. 노드 아래 월을 적고 지금 단계 노드만 금색으로 깜빡인다.
Ⅴ. 기대 효과퀘스트 완료 배너 + 보상 슬롯'퀘스트 완료!' 띠 아래 아이템 슬롯 4칸. 아이콘이 하나씩 들어오고 각 슬롯 아래 효과 이름 한 줄.
맺음·문의세이브 화면 (슬롯 3칸)세이브 슬롯 1 담당 부서, 2 협조 부서, 3 문의처. 마지막 장은 '저장했습니다' 대화창으로 닫는다.

발표 흐름: 어떤 게임 화면이 어떤 순서로 이어지는가

  1. 퀘스트 일지표지 · 장 이름에 커서
  2. 의뢰 대화추진 배경 · 게시판 + 대화창
  3. 퀘스트 수락목적·방침 · 체크박스 3 + 수락
  4. 퀘스트 상세 ×5세부 과제 · 커서가 한 칸씩
  5. 진행 단계추진 일정 · 노드 4칸
  6. 퀘스트 완료기대 효과 · 보상 슬롯 4칸
  7. 세이브맺음·문의 · 슬롯 3칸

재현 체크

  • 9-slice 창 테두리: 바깥 먹선 → 흰 선 → 회색 선 4겹, 모서리 1px 깎기. 안쪽은 파랑 3단 디더 그라데이션. → 목록·상세·대화 창 3개
  • 선택 커서 + 선택 테두리: 화살표 커서가 1px씩 위아래로 흔들림. → 계획 전체(장 이름)를 고른 상태
  • 목록 탭: 전체 / 메인 3 / 서브 2. → 과제 개수
  • 접이식 장 머리 + 메인 ★ / 서브 ◆ 표식 + 진행 수: → 핵심 과제 3, 연계 과제 2, 세부 사업 수 0/3·0/2
  • 목표 체크박스: 빈 칸 3개. → 추진 방침 3개
  • 보상 아이템 슬롯: 집·하트·새싹·회복약 도트 아이콘. → 기대 효과 4개
  • 대화창 + 초상화 + 이름표 + ▼ 대기 표시: → 추진 배경(학부모 돌봄 수요)
  • 상단 상태 바 + 버튼 안내: 화면 이름·부서·보고일·A 수락. → 기관, 날짜, 결재 요청
  • 진행 단계 트래커: 노드 4칸, 지금 단계만 깜빡임. → 준비·1학기·2학기·평가
  • 저해상도·제한 팔레트: 384×216, 16색, 글자도 캔버스 격자에 1비트로 찍음(안티에일리어싱 제거).

폰트
Galmuri11 / Galmuri11 Bold / Galmuri9 / Galmuri7 (OFL, 쓰인 글자만 잘라 내장) 대체: DotGothic16 → 둥근모꼴 → 맑은 고딕. 메모 본문은 Noto Sans KR.
해상도·배율
384×216 (16:9). ×5 = 1920×1080이 정확히 맞는다. 글자 크기는 격자 기준 Galmuri11 = 12px, 9 = 10px, 7 = 8px. 제목만 2배(한 칸 = 2×2 도트).
PPT로 옮기기
창·아이콘·초상화는 PNG로, 글자는 Galmuri를 설치해 텍스트 상자로. PPT는 작은 그림을 키우면 흐리게 보간한다. 그래서 384×216을 그대로 넣지 말고 아래 버튼으로 만든 ×5(1920×1080) PNG를 100% 크기로 넣는다. 글자 크기는 격자 12px × 5 = 60px ≈ 45pt, 10px → 37.5pt. 창을 늘릴 땐 9-slice가 없으니 모서리 4개와 변을 따로 그린 PNG를 붙이거나 창 크기별로 PNG를 따로 뽑는다. 그림 효과·그림자·둥근 모서리는 끈다.
난이도
상 HTML은 도트 엔진이 필요하고, PPT는 PNG 배치만 하면 되니 중.
