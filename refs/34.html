타일을 눌러 보세요. 숫자 키 1–6, Esc

가져갈 장치

질문이 오면 그 타일로 바로 점프보고 순서를 미리 정하지 않습니다. "인사는요?"라는 질문에 4번만 누르면 됩니다. 발표가 질의응답 중심의 대화가 됩니다.
타일이 화면 전체로 펼쳐지는 전환상세 화면이 눌린 타일 자리에서 펼쳐지고 같은 자리로 접힙니다. 청중이 지금 어느 분야를 보는지 놓치지 않습니다.
본 분야 체크와 미니맵허브에는 이미 설명한 분야에 ✓가 남고, 상세 화면 왼쪽 위 미니맵은 현재 타일 위치를 보여 줍니다. 남은 분야가 한눈에 보입니다.

동작 설명

첫 화면은 6개 분야의 대표 숫자를 크기 위계(예산 대형, 디지털 가로형, 나머지 소형)로 보여 주는 허브입니다. 타일을 누르면 그 타일의 위치와 모서리 모양에서 시작해 장표 전체로 펼쳐지며 핵심 수치 3개와 한 문장 결론이 나타나고, "허브로"를 누르면 원래 타일 자리로 접히면서 ✓ 표시가 붙습니다. 처음 열면 예산 타일이 한 번 열렸다 닫히는 데모가 돌고 허브에서 멈추며, 동작 줄이기 설정에서는 전환 없이 바로 바뀝니다.

응용 예 · 국정감사·도의회 업무보고 예상질의 대응, 부서 연간 성과 공유회, 신규 직원 업무 안내(분야 = 팀), 예산 설명회의 사업군별 질의응답.

    detail.classList.remove("is-veiled");
    if (!demo) { seen.add(i); detail.querySelector(".hub-back").focus({ preventScroll: true }); }
    busy = false;
  }

  async function close(chain = false) {
    if (current < 0 || (busy && !chain)) return;
    busy = true;
    const i = current;
    if (!reduce) {
      detail.classList.add("is-veiled");
      await new Promise(r => setTimeout(r, 140));
      const a = detail.animate([{ clipPath: FULL }, { clipPath: tileClip(i) }],
        { duration: DUR_CLOSE, easing: "cubic-bezier(.5,0,.2,1)", fill: "forwards" });
      await a.finished;
      detail.hidden = true; a.cancel();
    }
    detail.hidden = true; current = -1;
    paintSeen();
    if (!chain) tiles[i].focus({ preventScroll: true });
    busy = false;
  }

  function paintSeen() {
    tiles.forEach((t, j) => t.classList.toggle("is-seen", seen.has(j)));
    [...bar.children].forEach((b, j) => b.classList.toggle("on", j < seen.size));
    countEl.textContent = seen.size;
  }

  // 키보드: 1~6 섹션, Esc 허브
  document.addEventListener("keydown", e => {
    if (e.target.closest("input, textarea, [contenteditable]")) return;
    const i = HUB_SECTIONS.findIndex(s => s.key === e.key);
    if (i >= 0) { stopDemo(); open(i); }
    else if (e.key === "Escape" && current >= 0) { stopDemo(); close(); }
  });

  // 데모: 한 번 열렸다 닫히고 허브에서 멈춤 (본 섹션으로 세지 않음)
  function stopDemo() { demoTimers.forEach(clearTimeout); demoTimers = []; }
  if (HUB_DEMO) {
    demoTimers.push(setTimeout(() => open(0, true), 1400));
    demoTimers.push(setTimeout(() => close(true), 4400));
  }
})();
</script>

PPT로 옮기기

  1. 슬라이드 구성 · 1번 허브 슬라이드, 2~7번에 분야별 상세 슬라이드를 둡니다. 허브의 타일은 도형(둥근 사각형, 모서리 하나를 크게 둥글린 '한쪽 모서리 둥근 사각형')으로 그리고 크기 위계를 그대로 살립니다.
  2. 방법 A · 확대/축소(줌) · 분야별로 구역을 나눈 뒤 삽입 › 확대/축소 › 구역 확대/축소로 허브에 구역 썸네일을 넣습니다(구역이 없으면 요약 확대/축소가 요약 슬라이드와 구역을 함께 만들어 줍니다). 썸네일을 선택하고 확대/축소 탭 › 이미지 변경으로 직접 만든 타일 그림을 씌우고, 확대/축소로 돌아가기를 체크하면 상세를 다 본 뒤 허브로 돌아옵니다. 슬라이드쇼에서 썸네일을 누르는 순서는 자유입니다.
  3. 방법 B · 모핑으로 타일 확장 재현 · 허브 슬라이드를 복제해 상세 슬라이드로 만들고, 복제본에서 해당 타일 도형을 슬라이드 전체 크기로 키운 뒤 나머지 타일은 지우고 수치·결론을 얹습니다. 상세 슬라이드에 전환 › 모핑(1.0초 안팎)을 걸면 타일이 화면 전체로 펼쳐집니다. 도형 이름을 선택 창에서 허브·상세 양쪽 모두 !!예산처럼 같게 지정하면 모핑이 정확히 짝을 찾습니다.
  4. 점프와 복귀 · 허브의 각 타일 도형에 링크 › 이 문서 › 해당 상세 슬라이드 하이퍼링크를 걸고, 상세 슬라이드의 "허브로" 도형에는 1번 슬라이드 링크를 겁니다. 허브 슬라이드에도 모핑 전환을 걸어 두면 돌아갈 때 타일이 제자리로 접힙니다. 숫자 키 대신 발표자 보기에서 슬라이드 번호 입력 후 Enter로도 바로 이동합니다.
  5. 본 분야 체크 · PPT에는 방문 표시 기능이 없으므로, 타일 제목 글자에 하이퍼링크를 걸고 디자인 › 적용 › 색 › 색 사용자 지정에서 '열어 본 하이퍼링크' 색을 회색 등으로 지정하면 본 분야 제목 색이 바뀝니다.
