Ⅰ. 추진 배경!조립 전 주의 + 확대 원(2×)설명서의 ✕/✓ 비교 칸 두 개. 왼쪽은 이음판 없이 벌어진 두 칸(기관별로 다른 기준), 오른쪽은 이음판이 끼워진 상태. 현황 수치는 칸마다 하나만 둡니다.
Ⅱ. 목적·방침2인조립 인원 아이콘 + 필요 공구'1인 ✕ / 2인 ✓' 그림으로 공동 추진 방침을 한 장에 보여 줍니다. 방침 3개는 공구 3개(드라이버·육각렌치·시계)로 바꿔 아이콘 줄로 배치합니다.
Ⅲ. 세부 추진 과제A–E부품 목록 · 101–103철물 1:1분해도 한 장에 A–E 풍선을 모두 띄운 개요 장 1장, 이어서 과제별로 해당 부품만 파랗게 칠한 같은 분해도를 반복합니다. 수치는 철물 개수로 보여 줍니다.
Ⅳ. 추진 일정1–4조립 단계 번호장마다 큰 단계 번호를 왼쪽 위에 두고, 이전 단계에서 끼운 부품은 회색, 이번 단계 부품만 파랑. 날짜는 단계 번호 옆 작은 숫자로.
Ⅴ. 기대 효과✓완성품 + 보관 안내 + 문의처지붕이 다 내려앉은 완성품 한 장과 '보관하세요' 띠. 뒤표지는 고객 지원 페이지 형식으로 담당 부서와 문의 번호(가상)를 둡니다.

재현한 실물 요소 → 매핑

  • 제품명·모델 표기 → 계획안 제목, 'MODUM 27'(모둠, 2027)
  • 완성품 아이소메트릭 선화 → 한 지붕 아래 두 칸 = 통합된 영유아학교(기대 효과)
  • 부품 풍선(원 안 글자 + 지시선) → 과제 A–E를 그림 속 위치에 고정
  • 부품 목록(글자 코드·수량) → 세부 추진 과제 5개
  • 철물 실제 크기표 + 눈금자 → 핵심 수치(협의회 4회, 선도기관 12곳, 조례·규칙 3건)
  • 1인 ✕ / 2인 ✓ 조립 인원 → 교육청·시·군 공동 추진 방침
  • 필요 공구·소요 시간 → 추진 수단(실무협의체·컨설팅단), 추진 기간
  • 정렬 점선 + 하강 화살표 → 지붕(관리체계 일원화)을 얹는 중인 단계적 결합
  • 확대 원(2×) → 칸막이와 바닥이 만나는 이음부, 목심과 캠 잠금 = 연령 사이의 공백을 잇는 장치
  • 주의 삼각형 박스 → 추진 배경(같은 나이, 다른 기준)
  • 단계 번호 띠 → 추진 일정 1–4
  • EAN-13 바코드·품번·쪽 번호·보관 안내 → 문서번호, 기관·날짜. 바코드는 실제 EAN-13 규칙(패리티·체크 숫자)으로 인코딩했고, 매장 내부용 접두 '2'를 써서 실제 상품과 겹치지 않습니다.

PPT로 옮길 때

  1. 선화: 표지 SVG를 PPT에 삽입한 뒤 그룹 해제 → 도형으로 변환하면 면 하나하나가 도형이 되어 색만 바꿔 과제별 장표를 만들 수 있습니다.
  2. 직접 그릴 때는 직사각형에 3D 회전 → 등각: 위쪽 위로 프리셋을 걸어 윗면·옆면을 따로 만들고 회색 3단(#FFFFFF·#E6E7E2·#C9CBC5)을 칠합니다.
  3. 풍선은 원 + 직선 연결선으로 만들고 그룹으로 묶어 둡니다. 장마다 위치를 같게 두면 모핑 전환으로 지붕이 내려앉는 장면을 만들 수 있습니다(지붕 개체 이름을 '!!지붕'으로 통일).
