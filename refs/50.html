2027 ○○교육청 교육환경 개선 종합계획(안)

늘봄·돌봄 예산의 65%가 국비, 의존도가 가장 크다

열 너비 = 분야 예산, 칸 높이 = 재원 비율 → 칸 넓이 = 금액 · 국비 비율이 높은 분야부터 · 단위 억 원

가상 예시 · 자료: ○○교육청 2027 본예산(안) 재원별 편성 내역 재구성 17
계열 값 바꿔 보기

구조 STRUCTURE

분야 다섯 개를 가로로 세우고, 열의 너비를 분야 예산(억 원)에, 열 안 칸의 높이를 재원 비율에 맞췄다. 그래서 칸 하나의 넓이가 곧 그 분야·재원의 금액이고, 한 장에서 "어느 분야가 큰가"와 "그 분야가 무엇으로 채워지는가"를 같이 읽는다. 국비 칸을 바닥에 깔고 국비 비율이 높은 분야부터 세워, 국비 칸 윗변이 계단처럼 내려가며 의존도 순위를 보여 준다.

가져갈 장치 — 기준선 하나가 합계 막대의 경계로 이어진다: 국비 평균(42%) 점선을 오른쪽 합계 막대의 국비 윗변까지 끌고 가, 각 열이 평균보다 위인지 아래인지 눈금 없이 판별한다. 재원 이름은 범례 대신 합계 막대 옆에 한 번만 적는다.

응용 1 · 교원 구성

열 = 학교급(초·중·고·특수), 너비 = 교원 수, 칸 = 정규·기간제·강사 비율.

응용 2 · 학교폭력 심의 결과

열 = 유형(언어·신체·사이버 등), 너비 = 심의 건수, 칸 = 조치 호수 구간 비율.

응용 3 · 늘봄 프로그램 운영 주체

열 = 지역(○○구 등), 너비 = 참여 학생 수, 칸 = 학교 자체·지역 기관·대학 연계 비율.

HTML로 가져다 쓰기 CODE

  • 데이터는 스크립트 맨 위 MK_DATA 하나: 분야 이름과 재원별 금액만 바꾸면 너비·높이·비율·정렬이 다시 계산된다.
  • 강조 칸은 highlight: ['분야 이름', 재원 순번] 한 곳만. 제목의 강조 단어와 같은 값을 가리키게 한다.
  • 분위기는 .mk-slide 맨 위 --ds-* 묶음만 바꾼다. 아래 스펙 표의 계열 값을 그대로 붙여 넣으면 된다.
  • 국비 칸 글자는 --ds-surface, 나머지 칸 글자는 --ds-ink로 찍힌다. 그래서 --ds-c1은 진하게, --ds-c2·c3는 옅게 둔다.

(function () {
  var NS = 'http://www.w3.org/2000/svg';
  // 도식 자리(가상 px): 열 영역 x132~1196, 값 축 y770(0%)~300(100%), 합계 막대 x1276

  function el(tag, attr, parent, text) {
    var n = document.createElementNS(NS, tag);
    for (var k in attr) n.setAttribute(k, attr[k]);
    if (text != null) n.textContent = text;
    if (parent) parent.appendChild(n);
    return n;
  }
  function fmt(n) { return String(n).replace(/\B(?=(\d{3})+(?!\d))/g, ','); }
  // 반올림 합이 100이 되도록(최대 나머지 방식) — 표시용만, 도형은 실제 값
  function pct(arr) {
    var s = arr.reduce(function (a, b) { return a + b; }, 0);
    var raw = arr.map(function (v) { return v / s * 100; });
    var fl = raw.map(Math.floor), left = 100 - fl.reduce(function (a, b) { return a + b; }, 0);
    raw.map(function (r, i) { return [r - fl[i], i]; }).sort(function (a, b) { return b[0] - a[0]; })
      .slice(0, left).forEach(function (p) { fl[p[1]]++; });
    return fl;
  }

    el('text', { x: 114, y: 800, 'text-anchor': 'end', 'font-size': 16, class: 'mk-sub' }, ax, '비중');

    var x = G.x0;
    fields.forEach(function (f, fi) {

  }

PPT로 옮기기 POWERPOINT

뼈대 자리

  1. 슬라이드 크기 16:9(33.867×19.05cm). 가상 1px = 0.0212cm로 환산: 좌우 여백 1.69cm, 머리말 띠 위 0.85cm.
  2. 머리말 띠: 텍스트 상자 2개(왼쪽 "Ⅴ. 일정 및 예산", 오른쪽 계획안 이름 10pt) + 1pt 선, 높이 1.0cm.
  3. 제목 28pt 굵게, 한 줄. "65%"만 강조색. 그 아래 부제 12pt 보조색.
  4. 바닥 줄: "가상 예시 · 자료" 9pt 왼쪽, 쪽 번호 오른쪽.

도식 만들기

  1. 차트 대신 직사각형으로 그린다. 열 영역 너비 22.5cm에서 간격 0.17cm×4를 뺀 21.84cm를 예산 비율로 나눈다(늘봄 5.28 · 디지털 3.52 · 시설 9.16 · 진로 2.11 · 안전 1.76cm).
  2. 열 높이 9.95cm(=100%). 칸 높이 = 9.95 × 비율. 국비 칸을 맨 아래에 두고 [맞춤 → 아래쪽 맞춤].
  3. 칸 테두리는 배경색 2pt로 칸 사이를 가른다. 글자는 칸 왼쪽 0.3cm, 세로 가운데.
  4. 평균선: 1.25pt 파선, 바닥에서 9.95×0.42 = 4.18cm 높이. 합계 막대 국비 윗변까지 잇는다.
