가상 예시
페이지를 열면 제목이 한 글자씩, 이어서 약속 간판이 차례로 한 번 켜지고 멈춥니다.

Takeaway가져갈 장치

점등 순서로 약속을 하나씩 켜기

핵심 약속 3개를 간판처럼 따로 두고 말하는 순서대로 켭니다. 정책 3대 방향, 단계별 일정, 개선 전후 비교에도 그대로 씁니다.

제목이 가장 밝은 광원

어두운 바탕에서는 밝기가 곧 위계입니다. 제목만 흰 심에 넓은 번짐을 주고, 보조 간판은 색 심에 번짐을 줄여 한 단계 낮춥니다.

꺼진 유리관을 남겨 두기

꺼진 글자도 어두운 관으로 보이게 두면, 아직 켜지 않은 항목이 무엇인지 청중이 미리 압니다. 발표 중 "다음 약속"을 예고하는 장치가 됩니다.

Motion동작 설명

  1. 0.0초켜진 완성 화면으로 시작합니다. 썸네일과 공유 미리보기도 이 상태입니다.
  2. 1.4초모든 네온이 한꺼번에 꺼지고 어두운 유리관만 남습니다.
  3. 1.7~2.9초제목이 한 글자씩 "탁" 하고 두 번 깜빡인 뒤 켜집니다.
  4. 3.2~4.2초언제나 열림 → 한 번에 처리 → 기다림 없이 순서로 간판이 켜집니다.
  5. 이후모두 켜진 채로 멈춥니다. 반복 깜빡임은 없습니다. 동작 줄이기 설정이면 처음부터 정지 화면만 보입니다.

PPT로 옮길 때

  1. 제목 글자에 [도형 서식 → 텍스트 옵션 → 텍스트 효과 → 네온] 18pt 분홍, 글자 채우기는 흰색에 가까운 분홍.
  2. 글자별로 텍스트 상자를 나누거나, 애니메이션 [효과 옵션 → 텍스트 애니메이션: 문자 단위]로 나타내기를 겁니다(문자 사이 지연 20%).
  3. 깜빡임은 강조 → 깜박이기를 0.2초로 한 번만, [이전 효과 다음에]로 이어 붙입니다.
  4. 간판 3개는 각각 클릭할 때 나타내기로 두어 말하는 순서에 맞춰 켭니다.
  5. 꺼진 관은 같은 글자를 짙은 회분홍으로 복제해 뒤에 깔면 됩니다. 모핑은 "꺼진 장표 → 켜진 장표" 두 장으로 근사합니다.

(function(){
