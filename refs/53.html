밑줄 대조표

현행과 개선을 나란히 놓는 신구 대조표. 문장 전체를 비교하게 하지 않고, 바뀌는 말에만 취소선과 밑줄을 그어 눈이 그 말만 따라가게 했다. 가상 예시.

Ⅲ세부 추진과제
2027 ○○교육청 학교 업무 경감 추진 계획(안)

학교 행정 7개 절차의 처리 기간을 3분의 1로 줄인다

평균 처리 기간 11.3일 → 3.5일바뀌는 말만 표시 · 현행 취소선 → 개선 밑줄시행 2027. 1.~7.

가상 예시 · 출처: ○○교육청 학교 업무 실태조사(가상), 2026. 8. · 처리 기간 = 요청부터 완료까지 평균 근무일 14

← 좁은 화면에서는 장표를 옆으로 밀어 보세요.

계열 값 바꿔 보기

구조 설명 STRUCTURE

한 줄이 절차 하나다. 줄마다 분야, 업무와 담당 부서, 현행, 개선, 처리 기간, 시행 시기가 같은 순서로 놓인다. 계획안의 "현행 → 개선" 대비를 표 한 장으로 줄인 형태로, 업무 경감·제도 개선·규정 개정 과제에 그대로 맞는다.

처리 기간 열은 0~25일 선형 축을 열 머리에 달았다. 현행은 빈 틀, 개선은 채운 막대로 같은 자리에서 겹쳐 그리고, 둘 사이 빗금이 줄어든 기간이다. 맨 아래 평균 줄도 같은 축이다.

가져갈 장치: 바뀌는 말만 표시. 법령 신구조문대비표의 관례를 장표로 옮겼다. 현행 열은 흐린 글자에 바뀌는 말만 진한 취소선, 개선 열은 진한 글자에 바뀐 말만 굵은 밑줄. 청중은 두 문장을 처음부터 비교하지 않고 밑줄 친 말만 읽어도 무엇이 달라지는지 안다. 데이터에서는 [ ]로 감싸기만 하면 된다.

응용 예

  • 학교폭력 사안 처리: 단계별 현행·개선 절차와 처리 기간(접수→심의→조치). 바뀐 주체(학교 → 교육지원청)에 밑줄.
  • 학교 규칙·조례 개정: 조항별 현행·개정안. 처리 기간 열 대신 "적용 대상 학교 수" 막대.
  • 교육 예산 집행 절차: 계약·지출 단계별 개선. 기간 열은 "결재 단계 수"(빈 틀 5칸 → 채움 2칸)로 바꿔도 된다.

줄은 5~9개가 알맞다. 한 칸 문장은 두 줄 이내, 밑줄은 칸마다 한 곳만. 밑줄이 두 곳 이상이면 그 칸은 두 줄로 나눈다.

PPT로 옮기기 POWERPOINT

뼈대 자리 (슬라이드 33.867 × 19.05cm 기준)

  • 여백: 좌우 1.69cm, 머리말 띠 0.85~1.86cm(아래 0.75pt 연회색 선). 왼쪽 "Ⅲ 세부 추진과제", 오른쪽 계획안 이름 10pt.
  • 제목 2.3cm 위치, 28pt 굵게, "3분의 1"만 강조색. 3.6cm에 읽는 법 한 줄(12pt).
  • 표 영역 4.7~17.4cm, 바닥 줄 17.9cm(가상 예시·출처 9pt, 쪽 번호 오른쪽).

표 만들기

  1. [삽입 → 표] 6열 × 9행(머리 1 + 절차 7 + 평균 1). 열 너비 1.65 / 4.49 / 7.83 / 8.68 / 5.97 / 1.86cm, 행 높이 1.48cm 고정, 세로 가운데.
  2. 테두리는 가로선만: 줄 사이 0.5pt 연회색, 머리 아래·평균 위 1.5pt 남색. 현행|개선 사이에만 0.5pt 세로선.
  3. 현행 열 글자는 보조색, 바뀌는 말만 본문색 + [홈 → 글꼴 → 취소선]. 개선 열은 본문색, 바뀐 말만 굵게 + [밑줄 → 굵은 밑줄], 밑줄 색 = 보조 강조.
  4. 처리 기간: 표 위에 직사각형 두 개를 겹친다. 빈 틀 너비 = 현행 ÷ 25 × 3.81cm(테두리 1pt, 채우기는 [패턴 → 넓은 상향 대각선]), 그 위 채운 막대 너비 = 개선 ÷ 25 × 3.81cm. 높이 0.38cm, 왼쪽 끝을 같은 세로선에 맞춤([맞춤 → 왼쪽 맞춤]).
  5. 강조 줄(늘봄 강사 채용)만 흰 사각형을 행 뒤에 깔고 [그림자 → 바깥쪽 아래] 흐림 10pt, 투명도 80%.

순차 등장

  • 표는 한 개체라 행별로 나눌 수 없다. 행마다 바탕색 사각형으로 덮고 그 사각형에 [끝내기 → 사라지기]를 주거나, 행마다 표를 따로 만들어(1행짜리 표 9개) [나타내기 → 올라오기]를 준다.
  • 시작 "이전 효과와 함께", 재생 0.4초, 지연 0 / 0.1 / 0.2 … 0.8초(머리 → 7줄 → 평균). 전체 1.2초 안팎.
  • 인쇄·PDF에서 애니메이션이 빠져도 모든 문장·막대·숫자가 남는다.

계열 값 넣기

  • [디자인 → 적용 → 색 → 색 사용자 지정]: 텍스트/배경 어둡게 1 = --ds-ink, 밝게 1 = --ds-bg, 강조 1 = --ds-accent, 강조 2 = --ds-accent2, 강조 3~6 = --ds-c1~c4.
  • [글꼴 사용자 지정]: 제목 = 제목 글꼴, 본문 = 본문 글꼴. 처리 기간·시행 숫자만 고정폭 글꼴.
