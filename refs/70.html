01고친 곳

목록 화면 → 주인공 하나

목록은 모든 앱이 같은 무게라 포스터가 될 수 없다. 모아 하나를 골라 "흩어진 파일, 한 번에 모아." 한 문장과 3시간 → 20분 숫자로 크게 세웠다. 원본에서는 파일 카드 그림과 아이콘만 가져왔다.

손대지 않은 것모아 아이콘과 파일 카드 그림은 원본에서 오려 썼다(아이콘은 확대해 약간 흐림 — 인쇄용은 고해상도 아이콘으로 바꿀 것). 특정 회사의 앱 장터 로고·이름은 쓰지 않았다.

02가져갈 장치

01

앱 상세 페이지 = 리플렛 목차

아이콘·이름(표지) → 스크린샷(안쪽 세 면) → 평점·후기(접힘면) → 개인정보·버전 기록·정보(뒷면). 칸 순서가 이미 정해져 있다.

어떤 도구·프로그램 소개 리플렛이든

02

개인정보 라벨 = "써도 되나?"에 미리 답하기

초록 "수집하지 않음" 배지 하나가 공공기관에서 가장 먼저 나오는 질문을 막는다.

개인정보가 걱정되는 모든 도구 안내

03

스크린샷 문법

색 바탕 + 큰 문장 두 줄 + 아래에서 올라오는 휴대폰. 01 끌어 넣기 → 02 확인 → 03 저장.

사용법 3단계, 절차 안내

04

버전 기록 = 개선 이력

v1.2 한글 파일 지원 / v1.1 중복 기준 / v1.0 첫 배포. 도구가 살아서 나아지고 있음을 보여 준다.

04인쇄 전에

  • 포스터 A3 세로, 리플렛 A4 가로 양면 → 3단 접지(면 99mm, 접는 면은 97mm로 2mm 좁게 앉히면 깔끔).
  • 큰 파란 면은 C100 M70 정도로 탁해지기 쉽다 — 교정쇄로 확인.
  • 아이콘은 원본(120px) 확대본이라 인쇄 시 흐리다. 1024px 이상 아이콘을 이미지 AI로 다시 뽑아 바꿀 것(아래 프롬프트).
  • QR은 자리 표시용 무늬다. 실제 받는 곳 주소로 만든 QR을 2cm 이상으로.

06HTML 코드

  1. 코드를 빈 .html 파일로 저장하면 포스터 한 장이 그대로 열립니다(바탕 그림·글꼴 포함, 인터넷 연결 없이도).
  2. 문구는 마크업의 글자를, 위치·크기는 u 단위(지면 폭 기준) 숫자를 바꾸면 됩니다.
  3. 인쇄: 크롬에서 열고 인쇄 → PDF로 저장, 여백 없음, 배경 그래픽 켜기.
  4. AI 채팅에는 링크 대신 이 코드를 붙여 넣으세요.
