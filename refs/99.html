빛나는 단어 더미

사업의 키워드를 몽글몽글한 3D 글자 블럭으로 켜켜이 쌓아 두고, 불 꺼진 무대에서 시작한다. 한 번 누르면 행사 이름이 앞으로 톡톡 떨어지고, 그다음부터는 식순과 성과 키워드가 하나씩 더미 사이에서 반짝 솟아오른다. 리모컨 → 하나로 끝까지.

좁은 화면에서는 장표를 옆으로 밀어 보세요. 3D라서 처음 불러오는 데 몇 초 걸립니다.

장표를 누르거나 → 키로 진행

설계 메모 NOTES

쌓인 단어 = 한 해의 무게

앞 더미 49개 + 뒤 단어 벽 세 겹 약 200개. 양옆은 크고 높게, 가운데로 갈수록 작고 낮게 쌓아 노골적인 V자 없이 원근이 가운데로 모인다. 뒤 벽은 남색 안개에 묻혀 어둡고 흐리다.

불 꺼진 무대 → 행사 이름

첫 화면은 노출을 낮춰 어둡게 시작. 누르면 조명이 오르며 '유보통합 · 성과 · 공유회' 세 덩어리가 위에서 차례로 떨어져 통통 튀고(닿는 순간 살짝 눌렸다 펴짐) 맨 아래 가운데에 자리 잡는다.

반짝 = 솟아오름

빛날 단어는 흰빛으로 바뀌며 더미 사이에서 솟아 앞으로 크게(1.12배) 나오고, 뒤에 금빛 후광이 깔린다. 켜지는 순간 한 번 번쩍이고 별빛 일곱 개가 흩어지며, 나머지 단어는 절반 가까이 어두워진다. 글자 자체는 발광을 약하게 두어 입체 음영이 남아 있어야 읽힌다(노랗게 통째로 빛나면 획이 뭉개진다).

두 박자

→ 한 번: 단어가 반짝. → 한 번 더: 설명 카드가 빛나는 단어 반대편 위에 뜬다(왼쪽 단어면 오른쪽에). 발표자가 단어를 먼저 보여 주고 이어서 말한다. 마지막 박자는 여섯 단어가 모두 켜지는 장면.

자리 배치

국민의례 왼쪽 위 · 인사말씀 오른쪽 아래 앞 · 공감 왼쪽 가운데 · 변화 오른쪽 안쪽 · 소통 왼쪽 바깥 · 미래 오른쪽 바깥. 좌우를 번갈아 시선이 화면을 오가게 했다.

색

배경은 깊은 남색 그라데이션(신뢰), 글자는 따뜻한 파스텔 일곱 색(온기). 역할을 나눠 차갑지도 유치하지도 않게. 행사 이름만 크림 흰색으로 따로 뺐다.

인터넷 없이 쓰기 OFFLINE FILE

행사장 PC가 인터넷에 안 붙어 있어도 되는 HTML 파일 하나(4.2MB)입니다. 3D 엔진 · 글자 모양 · 글꼴이 모두 들어 있어 USB에 담아 가서 크롬 · 엣지로 열고 F(전체 화면)만 누르면 됩니다.

  1. 아래 버튼으로 받습니다. 받기 대신 새 창에 열리면 그 창에서 Ctrl+S로 저장하세요.
  2. 내용은 파일을 메모장으로 열어 const DATA 부분만 바꿉니다(행사 이름 · 빛날 단어 · 설명 줄).
  3. 3D 글자는 한글 2,350자(완성형) · 영문 · 숫자를 모두 그릴 수 있어 행사 이름이나 단어를 자유롭게 바꿔도 됩니다. '똠 · 햏' 같은 드문 글자만 빈칸이 됩니다.
파일 받기 (4.2MB)

HTML로 가져다 쓰기 COPY

  1. 아래 코드는 장표만 떼어 낸 완결 코드입니다. 빈 HTML 파일에 붙여 넣고 인터넷이 되는 PC의 크롬 · 엣지로 열어 F(전체 화면) 후 발표합니다. 3D 엔진(Three.js)과 글자 모양 파일을 인터넷에서 불러옵니다. 인터넷이 없는 PC라면 위 '인터넷 없이 쓰기' 파일을 쓰세요.
  2. 행사 이름과 설명 글은 스크립트 맨 위 DATA만 바꾸면 됩니다. title은 떨어지는 덩어리, items 한 칸이 빛날 단어 하나(설명 줄 · 아래 작은 글)입니다.
  3. 3D 글자는 글자 모양 파일에 든 글자만 그릴 수 있습니다. 이 코드가 불러오는 파일에는 이 장표에 쓰인 단어 130여 개 글자만 들어 있어, 새 단어(예: '돌봄')를 3D로 쌓거나 행사 이름을 바꾸면 그 글자가 빈칸이 됩니다. 이때는 위 오프라인 파일(한글 2,350자)을 쓰거나, facetype.js에 주아체 TTF(구글 폰트, OFL)를 넣어 JSON을 새로 만들고 FONT_URL을 그 파일로 바꾸세요. 설명 카드의 글은 일반 글꼴이라 아무 글자나 됩니다.
  4. 단어 자리는 WORDS(앞 더미)의 x · 높이 · z · 크기 숫자입니다. 빛날 단어는 DATA.items의 word와 같은 글자인 블럭이 자동으로 정해집니다.
  5. 행사장 PC가 오래되어 끊기면 BACK(뒤 단어 벽) 줄 수를 줄이세요. 뒤 벽만 빼도 그리는 양이 절반 이하로 줍니다.
  6. AI 채팅에는 링크 대신 이 코드를 붙여 넣으세요.

  


  

    
PPT로 옮기기 POWERPOINT

    
    
      
  1. 3D 글자: PPT는 글자 자체를 3D로 쌓기 어렵다. 이 장표 화면을 캡처해 배경 그림으로 쓰거나(가장 간단), [삽입 → 3D 모델]로 블렌더 등에서 만든 글자 모델(.glb)을 넣는다. 워드아트의 [3차원 서식 → 입체 효과: 둥글게, 깊이 30pt]로 비슷한 몽글한 글자를 만들 수도 있다.
    2. 
      
  2. 불 꺼진 시작: 첫 장은 같은 그림 위에 검정 사각형(투명도 45%)을 덮고, 다음 장에서 뺀 뒤 [전환 → 페이드] 0.8초.
    3. 
      
  3. 톡톡 떨어지는 행사 이름: 세 덩어리를 따로 글 상자로 두고 [애니메이션 → 나타내기 → 바운드] 0.9초, 두 번째 · 세 번째는 [이전 효과 다음에] 지연 0.3초.
    4. 
      
  4. 반짝: 빛날 단어 위치에 흰빛(#FFF7EA) 글자 + [서식 → 네온 효과: 금색 18pt]를 얹고 [나타내기 → 확대/축소] + [강조 → 펄스]. 나머지는 위에 반투명 남색 사각형(투명도 70%)을 덮어 어둡게.
    5. 
      
  5. 설명 카드: 남색 반투명 둥근 사각형(#0D162C, 투명도 28%) + 금색 제목 + 줄마다 [나타내기 → 떠오르기] 0.1초 간격. 단어 반대편 위에 둔다.
    6.
