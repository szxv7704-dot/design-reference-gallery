실험형 · 문화·관광 · 2026-09-30 · 재작업(#2 대체)

#2는 형광 2도와 바코드 하나로 탑승권을 암시하는 데 그쳤습니다. 이번에는 실제 탑승권의 필드 배치(본권·보관용 쪽·절취선·항공사 띠·필드 라벨)를 먼저 세우고, 리소그래프는 그 위에 찍히는 인쇄 방식으로만 썼습니다. 색과 글꼴을 빼도 필드 구조만으로 탑승권으로 읽힙니다. 바코드 두 개는 실제 PDF417·Aztec 인코딩이라 스캔하면 사업 요약이 나옵니다.

Flow사업 단계와 탑승권 요소 매핑

출발 = 현재, 경유 = 연차별 핵심 프로그램, 도착 = 목표. 경유 순서와 탑승 그룹 번호가 사업 단계(1·2·3단계)와 같습니다. 모든 수치는 가상 사업의 설계용 가정값입니다.

  3. 항공사 띠 — 가상 항공사 '가온 나이트라인'
  4. 승객 성명 — 보고 기관(관광진흥과)
  5. 편명 GN 2027 — 사업 코드·착수 연도
  6. 날짜 30SEP26 — 보고일(DDMMMYY 표기)

  8. 경유 VIA — MKT·RVR·STY 세 프로그램
  9. 탑승 시각 ≠ 출발 시각 — 18:20 일몰 무렵 / 19:00 개장

PPT 재현 방법과 주의점

  • 크기 환산: 슬라이드 13.333in 기준 1cqw = 0.133in ≈ 9.6pt. 필드 라벨 0.82cqw ≈ 8pt, 값 1.6cqw ≈ 15pt, 공항 코드 5.6cqw ≈ 54pt.
  • 필드: 필드마다 텍스트 상자 두 개(라벨 8pt / 값). 탑승·출발·탑승구·그룹·운임 줄은 1행 5열 표로 만들고 테두리만 블루 1pt.
  • 노치와 절취선: 사각형에서 원 두 개를 '도형 병합 → 빼기'로 파냅니다. 절취선은 '둥근 점' 점선.
  • 판 어긋남: 제목·공항 코드 텍스트를 복제해 핑크로 바꾸고 오른쪽 아래로 1~2pt 옮긴 뒤 뒤로 보냅니다. PPT에는 곱하기 혼합이 없으니 핑크에 투명도 15~25%를 줍니다.
  • 입자: 투명 배경 노이즈 PNG를 맨 위에 한 장 덮습니다(투명도 60~70%). 발표 화면이 흐려 보이면 빼도 됩니다.
  • 바코드: bwip-js 같은 생성기로 PDF417·Aztec을 SVG로 뽑아 삽입하고 '도형으로 변환' 후 블루로 칠합니다. 가짜 막대 무늬 대신 실제 코드를 쓰세요.
  • 주의: 형광 핑크는 화면(RGB)에서만 형광으로 보이고 CMYK 인쇄에서는 탁해집니다. 폰트 3종은 설치·포함해야 하며, 없으면 맑은 고딕으로 바뀌어 감열 인쇄 느낌이 사라집니다.
