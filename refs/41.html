Ⅰ. 현황노선별 일평균 승객 순위 변화 (2019 → 2025)

동작 설명

자동차 경주 중계의 타이밍 타워(오른쪽 세로 순위표)와 범프 차트(순위 궤적)를 같은 줄무늬 위에 붙였습니다. 한 해가 한 바퀴(LAP)입니다. 바퀴가 돌 때마다 타워의 줄이 새 순위로 미끄러져 자리를 바꾸고, 왼쪽에는 그 노선이 지나온 순위 궤적이 한 칸씩 이어집니다.

궤적의 앞머리가 언제나 타워의 같은 줄 높이에 닿습니다. 그래서 재생이 끝난 뒤에도 "어디서 출발해 몇 계단을 올랐는가"가 한 화면에 남습니다. 아래 레이스 컨트롤 줄은 그해 순위를 흔든 사건을 한 줄로 알리고, 깃발은 사건이 일어난 해에 꽂혀 남습니다.

가져갈 장치

  • 타워 + 궤적 접합: 표(현재 값)와 그래프(지나온 길)를 같은 줄 높이로 맞춰 한 장에 둡니다.
  • 출발 대비 칩 ▲▼: 직전 해가 아니라 출발 연도와 비교해, 최종 화면만 봐도 누적 변화가 보입니다.
  • 레이스 컨트롤 한 줄: 도식 위에 말풍선을 얹지 않고 아래 고정 줄에서 원인을 해설합니다.

응용 예

  • 민원 유형별 접수 건수 순위 변화(분기 = 바퀴)
  • 관광지별 방문객 순위, 축제 개최 전후 비교
  • 부서별 예산 집행률 순위를 월별로(타워 값 = 집행률 %)

HTML로 가져다 쓰기

  • 노선·값은 스크립트 맨 위 DATA.routes에서 바꿉니다. 순위와 궤적은 값으로 자동 계산됩니다.
  • 연도는 DATA.years, 사건 깃발은 DATA.flags(at = 연도 위치), 아래 해설 줄은 DATA.messages(연도 수와 같게).
  • 제목·부제는 .tt-title, .tt-lede 글자를, 색은 .tt-wrap의 --tt- 변수만 고치면 됩니다.
  • 줄 수를 바꾸면 .tt-bands 안의 div 개수도 같게 맞춥니다.

  // 곡선 한 구간(앞 점 → 뒤 점)을 t만큼만 그린다 (de Casteljau 분할)
  function seg(x0, y0, x1, y1, t) {

        const s = seg(X(i-1), Y(ranks[i-1][ri]), X(i), Y(ranks[i][ri]), t);
        d += s.c; end = s.end;
      }
      paths[ri].setAttribute('d', d);
      dots[ri].style.left = end[0] + '%'; dots[ri].style.top = end[1] + '%';
    });
    flagEls.forEach(o => { const on = p >= o.f.at - .02 ? 1 : 0; o.line.style.opacity = on; o.lab.style.opacity = on; });
  }
  // 타워를 해당 연도로 맞춘다
  function setTower(lap, prevLap) {
    rows.forEach((row, ri) => {
      const rk = ranks[lap][ri];
      const pk = ranks[prevLap][ri];
      row.style.zIndex = rk < pk ? 3 : rk > pk ? 1 : 2; // 추월하는 줄이 위로 지나간다
      row.style.top = (rk * 100 / N) + '%';
      row.querySelector('.tt-pos').textContent = rk + 1;
      const diff = ranks[0][ri] - rk, chip = row.querySelector('.tt-chip');
      chip.textContent = diff > 0 ? '▲' + diff : diff < 0 ? '▼' + (-diff) : '–';
      chip.style.background = diff > 0 ? css('--tt-up') : diff < 0 ? css('--tt-down') : '#AEB9C2';
      tweenNum(row.querySelector('.tt-val'), DATA.routes[ri].v[prevLap], DATA.routes[ri].v[lap]);
    });
    lapEl.textContent = `LAP ${lap + 1}/${L + 1}`;
    yearEl.textContent = DATA.years[lap];
    msgEl.textContent = DATA.messages[lap];
    yearsEl.querySelectorAll('span').forEach((s, i) => s.classList.toggle('on', i === lap));
  }
  function tweenNum(el, a, b) {
    if (reduce || a === b) { el.textContent = b.toFixed(1); return; }
    const t0 = performance.now();
    (function f(now) { const k = Math.min(1, (now - t0) / STEP_MS); el.textContent = (a + (b - a) * k).toFixed(1); if (k < 1) requestAnimationFrame(f); })(t0);
  }

  let lap = L, raf = 0, timer = 0;
  function goTo(next, animate) {
    cancelAnimationFrame(raf);
    const from = lap; lap = next;
    setTower(lap, animate ? from : lap);
    if (!animate || reduce || next < from) { drawLines(lap); return; }
    const t0 = performance.now();
    (function f(now) {
      const k = Math.min(1, (now - t0) / STEP_MS), e = k < .5 ? 2*k*k : 1 - Math.pow(-2*k + 2, 2) / 2;
      drawLines(from + (next - from) * e);
      if (k < 1) raf = requestAnimationFrame(f);
    })(t0);
  }
  function stop() { clearTimeout(timer); }
  function play() {
    stop();
    rows.forEach(r => r.style.transition = 'none'); goTo(0, false);
    void tower.offsetHeight; rows.forEach(r => r.style.transition = '');
    const tick = () => { if (lap < L) { goTo(lap + 1, true); timer = setTimeout(tick, STEP_MS + GAP_MS); } };
    timer = setTimeout(tick, 500);
  }
  root.querySelector('[data-act="replay"]').addEventListener('click', play);
  root.querySelector('[data-act="step"]').addEventListener('click', () => {
    stop();
    if (lap >= L) { rows.forEach(r => r.style.transition = 'none'); goTo(0, false); void tower.offsetHeight; rows.forEach(r => r.style.transition = ''); }
    else goTo(lap + 1, true);
  });

  // 처음: 완성 화면 → 잠시 뒤 처음부터 한 번 재생 → 최종 화면에서 정지
  rows.forEach(r => r.style.transition = 'none'); goTo(L, false);
  void tower.offsetHeight; rows.forEach(r => r.style.transition = '');
  if (!reduce) timer = setTimeout(play, 900);
})();
</script>

PPT로 옮기기

핵심은 모핑 전환입니다. 연도 하나를 슬라이드 하나로 만들고(7장), 같은 노선의 개체 이름을 모든 장에서 똑같이 맞추면 PowerPoint가 줄의 이동과 궤적의 늘어남을 자동으로 이어 줍니다.

  1. 밑판 만들기: 1장에 줄무늬 8줄(사각형), 오른쪽에 타워 줄 8개를 만듭니다. 줄 하나 = 그룹(흰 사각형 + 순위 숫자 + 색 막대 + 노선 번호 + 값 + 칩).
  2. 이름 붙이기: [홈] → [정렬] → [선택 창]에서 그룹 이름을 !!r512, !!r515…처럼 노선마다 !!로 시작하게 바꿉니다. 궤적 선은 !!l512, 끝점 원은 !!d512. !!로 시작하는 이름은 모핑이 "같은 개체"로 짝을 짓습니다.
  3. 장 복제: 1장을 6번 복제(Ctrl+D)하고, 장마다 타워 줄 그룹을 새 순위 위치로 옮기고 값·칩 글자를 고칩니다. 궤적은 [삽입] → [도형] → [자유형: 곡선]으로 그해까지 이어 그린 선을 같은 이름으로 바꿔 넣습니다.
  4. 전환 적용: 2~7장을 모두 선택 → [전환] → 모핑, 효과 옵션 개체, 기간 00.90. 화면 전환 시점은 클릭(한 단계씩) 또는 [다음 시간 후] 01.25(자동 재생).
  5. 사건 깃발: 4장(2022)에 깃발·점선을 넣고 [애니메이션] → 나타내기, 시작 이전 효과 다음에, 지연 00.50. 5장부터는 애니메이션 없이 그대로 둡니다.
  6. 레이스 컨트롤 줄: 해설 글상자 이름을 !!msg로 두고 장마다 문장만 바꿉니다. 모핑 효과 옵션을 단어로 바꾸면 글자가 바뀌는 느낌이 납니다(이 경우 줄 이동도 단어 단위로 처리되니 개체 옵션과 비교해 고르세요).
