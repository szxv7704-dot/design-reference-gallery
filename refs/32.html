레퍼런스 #32 · 재생지 콜라주 표지

주제 ‘학교 탄소중립 실천’을 다시 쓴 종이(골판지, 크라프트지, 신문지, 색종이, 영수증)로 찢어 붙였습니다. 재료가 곧 메시지라서, 표지를 보는 순간 ‘다시 쓰기’가 먼저 전달됩니다.

가져갈 장치 TAKEAWAY

재료가 주제를 말하는 표지

재활용을 말할 때 재생지로 만들고, 물을 말할 때 젖은 종이로 만드는 식입니다. 설명 문장 없이 재료가 첫 메시지를 맡습니다.

다른 발표: 예산 절감 보고는 영수증 뒷면, 기록물 정리는 서류철 표지 질감.

종이 조각 크기로 비율 보여 주기

감축 목표 4개 영역을 면적이 비율과 같은 종이 조각(트리맵)으로 붙였습니다. 축과 눈금이 없어도 크기 차이가 바로 보입니다.

다른 발표: 예산 구성, 업무 비중, 민원 유형 비율. 영역은 3~5개까지가 읽기 좋습니다.

한 줄에 한 장, 제목 조각

제목을 줄마다 다른 종이에 올리면 줄 사이 위계가 자연스럽게 생깁니다. 핵심어 한 줄만 진한 색종이로 키웁니다.

다른 발표: “2027 / 핵심어 / 계획(안)” 세 줄 구조에 그대로 적용.

흐름 설계 메모 READING ORDER

  1. 0~1초
    “탄소중립” 녹색 조각

    가장 크고 유일하게 진한 색이라 눈이 먼저 갑니다. 위아래 줄이 연도와 문서 성격(계획안)을 붙여 줍니다.

  2. 1~3초
    종이 재료 알아차리기

    찢긴 흰 섬유 가장자리, 테이프, 스테이플이 ‘손으로 붙였다’는 신호를 줍니다. 여기서 재생지 은유가 읽힙니다.

  3. 3초 뒤
    오른쪽 콜라주 차트

    골판지 조각이 절반 가까이를 차지해 “에너지가 제일 크다”는 결론이 숫자보다 먼저 보입니다.

  4. 마지막
    기관·날짜

    왼쪽 아래 작게. 장식 없이 바탕에 바로 씁니다.

표현 수준은 ‘종이’ 하나로 통일했습니다. 사진, 벡터 아이콘, 그라데이션 광택은 넣지 않았습니다. 지구와 잎도 색종이를 오린 모양입니다.

제목 글꼴은 굵고 획이 단순해 ‘오려 붙인 글자’처럼 보입니다. 손글씨체는 짧은 라벨에만 씁니다.

PPT 이식: 종이 조각 PNG 레이어

  1. 종이 재료를 실제로 찢어 스캔하거나, 무료 종이 텍스처 위에 찢긴 모양 마스크를 씌워 투명 PNG 6~8장을 만듭니다.
  2. PNG를 슬라이드에 놓고 그림 효과 → 그림자(바깥쪽, 아래, 흐리게 4pt, 투명도 70%)로 두께를 줍니다.
  3. 제목·라벨은 PNG 위에 텍스트 상자로 따로 얹어 수정 가능하게 둡니다. 회전은 ±2도 이내.
  4. 차트 조각은 표 비율대로 사각형을 먼저 그리고, 같은 크기로 PNG를 잘라 맞춥니다.
  5. 연출: 조각마다 ‘나타내기 → 확대/축소’ 0.4초, 이전 효과 다음에.
