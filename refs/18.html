레퍼런스 #18 함께 도는 궤도
궤도면 기울기
90°로 바꾸면 인터넷에 도는 '소용돌이 태양계' 영상처럼 궤도면이 진행 방향에 수직이 됩니다. 실제는 약 60°입니다.

MEMO 1계획안 구성 ↔ 은유 매핑

계획안 전체를 "태양계가 함께 은하를 도는 여정"으로 읽습니다. 정보 구조는 위계가 아니라 관계·공존입니다. 누가 누구를 끌고 가지 않고, 모두가 같은 중심을 공유하며 각자의 궤도를 돕니다.

계획안 구성은유 요소안쪽 장표 레이아웃 아이디어
표지나선 궤적 전체60° 궤도면 · 진행 방향지금 이 표지. 발표 시작 때 일시정지 상태로 두었다가 "같은 방향으로 갑니다"에서 재생.
Ⅰ. 추진 배경지구 = 학생 한 명의 출발점지구 하나만 크게 렌더링하고 대기 림라이트 둘레에 현황 수치 3개(특수교육대상학생 수, 일반학교 배치 비율, 통합학급 수). 수치는 실제 통계로 교체.
Ⅱ. 비전·목표태양 = 공동 목표태양을 화면 가운데, 코로나 빛 고리 위에 비전 한 문장과 목표 3개. 모든 행성이 같은 태양을 공유한다는 점을 그대로 보여 줍니다.
Ⅲ-1. 개별화교육 내실화각자의 궤도와 주기행성별 궤도 반지름·공전 주기 표를 개별화교육계획(IEP)의 목표·속도·평가 시점 표로 바꿉니다. "빠르다/느리다"가 아니라 "주기가 다르다".
Ⅲ-2. 통합학급 수업 지원수성·금성 = 가까운 두 궤도특수학급과 통합학급 궤도를 겹쳐 그리고 두 궤도가 가까워지는 구간에 협력교수·보조인력·통합학급 교사 연수를 배치.
Ⅲ-3. 지원센터 순회·진단목성 = 큰 중력의 지원목성 하나를 크게, 띠 무늬마다 서비스(진단·평가, 순회교육, 치료지원, 보조공학)를 한 줄씩.
Ⅲ-4. 가정·지역사회 연계화성·토성 고리 = 연계망토성 고리를 동심원 표로 펼쳐 안쪽부터 가정, 복지관, 진로·직업 기관, 지자체 순으로 연계 기관을 둡니다.
Ⅳ. 추진 일정나선 한 바퀴 = 한 분기지구의 나선 궤적을 가로로 펼쳐 한 바퀴마다 분기 마일스톤. 나선이 끊기지 않는다는 점이 연속 지원의 근거.
Ⅴ. 기대 효과함께 나아간 거리모든 궤적이 같은 방향으로 길어진 마지막 장면을 정지 화면으로 쓰고 성과 지표를 궤적 끝에 붙입니다.
  1. 1 · 출발지구 한 점에서학생 한 명의 현재 위치와 현황
  2. 2 · 중심같은 태양을 공유모두가 함께 배우는 학교라는 공동 목표
  3. 3 · 궤도각자의 궤도개별화교육, 주기가 다른 지원 주체들
  4. 4 · 나선함께 그리는 나선통합학급·센터·가정·지역의 공존과 연계
  5. 5 · 방향같은 방향으로일정과 기대 효과, 함께 나아간 거리

MEMO 2과학 사실 확인

  • 태양계는 은하 중심을 향해 가지 않습니다. 은하 중심에서 약 2만 6천 광년 떨어진 곳에서 중심 둘레를 초속 약 220~230 km로 돌며, 한 바퀴(은하년)에 약 2억 3천만 년이 걸립니다.
  • 행성 궤도면(황도면)은 태양의 진행 방향에 대해 약 60° 기울어 있습니다. 그래서 행성은 태양과 함께 나아가며 비스듬한 나선(헬릭스)을 그립니다.
  • 인터넷에 퍼진 '소용돌이 태양계' 영상은 궤도면을 진행 방향에 수직(90°)으로 그렸고, 태양이 혜성처럼 행성을 끌고 가며 행성이 뒤쫓는 모습으로 표현했습니다. 실제 행성은 태양 뒤로 처지지 않고 태양 둘레를 돕니다. 표지의 "흔한 오류 90°" 버튼으로 비교할 수 있습니다.
  • 축척 압축: 실제로는 지구가 한 바퀴 도는 동안 태양이 지구 궤도 둘레의 약 7.7배(230 ÷ 30 km/s)를 나아가 나선이 훨씬 길게 늘어납니다. 행성 크기·거리·공전 속도도 보기 좋게 줄였습니다. 공전 순서(안쪽일수록 빠름)는 지켰습니다.
  • 은하 지도 인셋의 나선팔은 모식도입니다. 은하 회전 방향(북은하극에서 볼 때 시계 방향)과 팔이 뒤로 감기는 방향만 맞췄습니다.

표현 수준

  for(const k of ORDER){const b=B[k];ctx.beginPath();for(let i=0;i<=72;i++){const a=i/72*TAU,cc=Math.cos(a)*b.a,ss=Math.sin(a)*b.a;const q=[cc*BS.e1[0]+ss*BS.e2[0],cc*BS.e1[1]+ss*BS.e2[1],cc*BS.e1[2]+ss*BS.e2[2]];const p=proj(cam(q));i?ctx.lineTo(p[0],p[1]):ctx.moveTo(p[0],p[1]);}ctx.stroke();}
  // trails: helices traced through the galaxy
  ctx.lineCap='round';ctx.lineJoin='round';
  const SEG=13;
  const drawTrail=(fn,col,lw)=>{const pts=[];for(let i=0;i<=NTR;i++){const tt=t-TT+TT*i/NTR;pts.push(proj(cam(fn(tt))));}
    ctx.strokeStyle=col;for(let s0=0;s0<NTR;s0+=SEG){const k=(s0+SEG)/NTR;ctx.globalAlpha=Math.pow(k,1.6)*.95;ctx.lineWidth=lw*pts[s0][2];ctx.beginPath();for(let i=s0;i<=Math.min(NTR,s0+SEG);i++){const p=pts[i];i===s0?ctx.moveTo(p[0],p[1]):ctx.lineTo(p[0],p[1]);}ctx.stroke();}ctx.globalAlpha=1;};
  drawTrail(tt=>[V*(tt-t),0,0],'#FFD27A',2.6*DPR);
  for(const k of ORDER){const b=B[k];drawTrail(tt=>{const o=off(b,tt);return [V*(tt-t)+o[0],o[1],o[2]];},b.trail,1.5*DPR);}
  // bodies, back to front
  const items=[{k:'sun',c:cam([0,0,0])}].concat(ORDER.map(k=>({k,c:cam(off(B[k],t))})));
  items.sort((a,b)=>a.c[2]-b.c[2]);
  const labels=[];
  for(const it of items){const p=proj(it.c);
    if(it.k==='sun'){const r=.5*K*p[2];drawSun(ctx,p[0],p[1],r,4.2);labels.unshift([p[0],p[1],r,'태양 · 공동 목표',1]);continue;}
    const b=B[it.k],r=b.R*K*p[2];
    const l=[-it.c[0],-it.c[1],-it.c[2]],ll=Math.hypot(...l);const L=[l[0]/ll,l[1]/ll,l[2]/ll];
    if(b.ring){drawSaturn(b,it.c,p,r,L);}else drawSphere(ctx,b,p[0],p[1],r,L,b.spin*t);
    labels.push([p[0],p[1],r,b.name,0]);
  }
  // direction of motion + tilt angle
  const v0=proj(cam([.75,0,0])),v1=proj(cam([5.9,0,0]));
  ctx.setLineDash([5*DPR,5*DPR]);ctx.strokeStyle='rgba(255,255,255,.85)';ctx.lineWidth=1.4*DPR;ctx.beginPath();ctx.moveTo(v0[0],v0[1]);ctx.lineTo(v1[0],v1[1]);ctx.stroke();ctx.setLineDash([]);
  const an=Math.atan2(v1[1]-v0[1],v1[0]-v0[0]),ah=9*DPR;ctx.fillStyle='#FFFFFF';ctx.beginPath();ctx.moveTo(v1[0]+Math.cos(an)*ah,v1[1]+Math.sin(an)*ah);ctx.lineTo(v1[0]+Math.cos(an+2.6)*ah,v1[1]+Math.sin(an+2.6)*ah);ctx.lineTo(v1[0]+Math.cos(an-2.6)*ah,v1[1]+Math.sin(an-2.6)*ah);ctx.fill();
  ctx.font=`700 ${fs}px "Gothic A1",sans-serif`;halo(ctx,'진행 방향',v1[0]-4*DPR,v1[1]-fs*1.6,'#FFFFFF','right');
  ctx.font=`500 ${fs*.9}px "Gothic A1",sans-serif`;halo(ctx,'은하 공전 · 초속 약 230 km',v1[0]-4*DPR,v1[1]-fs*.45,'#E6E9FA','right');
  // angle between motion and orbital plane
  const n=BS.n;let pp=[1-n[0]*n[0],-n[0]*n[1],-n[0]*n[2]];let pl=Math.hypot(...pp);if(pl<1e-3){pp=BS.e2.slice();pl=1;}pp=pp.map(x=>x/pl);
  const ang=Math.acos(clamp(pp[0],-1,1)),RA=1.15;
  ctx.strokeStyle='#FFD27A';ctx.lineWidth=1.8*DPR;ctx.beginPath();
  for(let i=0;i<=24;i++){const k=i/24,a=ang*k;const s1=Math.sin(ang-a)/Math.sin(ang),s2=Math.sin(a)/Math.sin(ang);const d=[s1+s2*pp[0],s2*pp[1],s2*pp[2]];const p=proj(cam([d[0]*RA,d[1]*RA,d[2]*RA]));i?ctx.lineTo(p[0],p[1]):ctx.moveTo(p[0],p[1]);}ctx.stroke();
  const pe=proj(cam([pp[0]*2.4,pp[1]*2.4,pp[2]*2.4])),ps=proj(cam([0,0,0]));
  ctx.strokeStyle='rgba(255,210,122,.7)';ctx.lineWidth=1.1*DPR;ctx.beginPath();ctx.moveTo(ps[0],ps[1]);ctx.lineTo(pe[0],pe[1]);ctx.stroke();
  const am=ang/2,dm=[Math.sin(ang-am)/Math.sin(ang)+Math.sin(am)/Math.sin(ang)*pp[0],Math.sin(am)/Math.sin(ang)*pp[1],Math.sin(am)/Math.sin(ang)*pp[2]],pm=proj(cam([dm[0]*1.9,dm[1]*1.9,dm[2]*1.9]));
  ctx.font=`600 ${fs}px "Martian Mono",monospace`;const at=tilt>1.5?'90° ✕':'≈ 60°',aw=ctx.measureText(at).width;halo(ctx,at,pm[0],pm[1]+fs*.35,'#FFE3A6','center');
  const used=[[pm[0]-aw/2,pm[1]-fs*.7,aw,fs*1.2],[v1[0]-W*.3,v1[1]-fs*2.6,W*.3,fs*2.5]];
  const hit=(r)=>used.some(u=>r[0]<u[0]+u[2]&&r[0]+r[2]>u[0]&&r[1]<u[1]+u[3]&&r[1]+r[3]>u[1]);
  // labels
  for(const lb of labels){const [x,y,r,txt,sun]=lb;ctx.font=`${sun?700:600} ${fs*(sun?.95:.88)}px "Gothic A1",sans-serif`;const w=ctx.measureText(txt).width,h=fs*1.05,g=4*DPR;
    const cand=sun?[[x+r*.75,y-r*.95],[x-r*.75-w,y-r*.95],[x+r*.8,y+r+h]]:[[x+r+g,y-r-g],[x+r+g,y+r+h],[x-r-g-w,y-r-g],[x-r-g-w,y+r+h]];
    for(const c of cand){const rc=[c[0],c[1]-h*.85,w,h];if(!hit(rc)){used.push(rc);halo(ctx,txt,c[0],c[1],'#FFFFFF');break;}}}
  // caption
  ctx.font=`700 ${fs*1.05}px "Gothic A1",sans-serif`;halo(ctx,'은하를 함께 도는 여정',W*.035,H*.915,'#FFFFFF');
  ctx.font=`500 ${fs*.82}px "Gothic A1",sans-serif`;halo(ctx,'궤도면은 진행 방향에 약 60° 기울어 있음 · 크기·거리·속도는 축척 압축',W*.035,H*.915+fs*1.35,'#F4EEE6');
}
function drawSaturn(b,c,p,r,L){
  const tl=.47,cs=Math.cos(tl),sn=Math.sin(tl);
  const r1=BS.e1,r2=[BS.e2[0]*cs+BS.n[0]*sn,BS.e2[1]*cs+BS.n[1]*sn,BS.e2[2]*cs+BS.n[2]*sn];
  const cr1=cam(r1),cr2=cam(r2);const ph=Math.atan2(cr2[2],cr1[2]);
  const R=b.R,arc=(a0,a1)=>{for(const g of RINGS){const pts=[];for(let i=0;i<=40;i++){const a=a0+(a1-a0)*i/40;pts.push([Math.cos(a),Math.sin(a)]);}
      ctx.beginPath();pts.forEach((q,i)=>{const pt=proj([c[0]+(q[0]*cr1[0]+q[1]*cr2[0])*R*g[1],c[1]+(q[0]*cr1[1]+q[1]*cr2[1])*R*g[1],c[2]]);i?ctx.lineTo(pt[0],pt[1]):ctx.moveTo(pt[0],pt[1]);});
      for(let i=pts.length-1;i>=0;i--){const q=pts[i];const pt=proj([c[0]+(q[0]*cr1[0]+q[1]*cr2[0])*R*g[0],c[1]+(q[0]*cr1[1]+q[1]*cr2[1])*R*g[0],c[2]]);ctx.lineTo(pt[0],pt[1]);}
      ctx.closePath();ctx.fillStyle=g[2];ctx.fill();}};
  arc(ph+Math.PI/2,ph+1.5*Math.PI);
  drawSphere(ctx,b,p[0],p[1],r,L,b.spin*t);
  arc(ph-Math.PI/2,ph+Math.PI/2);
}
