레퍼런스 #35 · 실무형 · 세로 스와이프

메신저로 바로 보내는 세로 카드 발표

회의실 화면이 아니라 휴대폰에서 읽히는 발표입니다. 화면은 9:16, 위쪽 막대로 남은 분량을 보여 주고, 카드를 넘기면 다음 장이 옆에서 밀려 들어오며 지난 장은 뒤로 깔립니다. 예시는 가상의 ○○교육청 2027 신규 공무원 온보딩 안내입니다.

가져갈 장치

메신저 공유용 세로 카드

9:16 한 장에 제목 한 줄, 핵심 2~3줄, 큰 숫자 하나. 단톡방이나 업무 메신저에 링크로 보내면 휴대폰에서 그대로 넘겨 봅니다.

스토리형 진행 막대

카드 수만큼 나뉜 막대가 지금 몇 장째이고 몇 장 남았는지 알려 줍니다. 쪽번호보다 먼저 눈에 들어옵니다.

카드 스택 깊이 전환

지난 카드는 작아지며 뒤로 깔리고 새 카드가 위로 덮습니다. 앞뒤 순서가 공간으로 보여서 되돌아가기도 자연스럽습니다.

동작 설명

  1. 처음 열면 표지 카드가 완성된 상태로 보입니다. 1초쯤 뒤 자동 데모로 두 장을 넘겼다가 표지로 한 번 돌아오고, 그 뒤로는 멈춥니다. 화면을 만지거나 키를 누르면 데모는 바로 멈춥니다.
  2. 넘기기: 왼쪽으로 스와이프하거나 마우스로 끌기, 화면 오른쪽 2/3 탭, → 키. 되돌리기: 오른쪽으로 스와이프, 왼쪽 1/3 탭, ← 키.
  3. 끌고 있는 동안 다음 카드가 손가락을 따라 들어옵니다. 화면 폭의 20% 넘게 끌고 놓으면 넘어가고, 덜 끌면 제자리로 돌아갑니다.
  4. 진행 막대는 지난 칸과 현재 칸을 채우고, 현재 칸만 그 카드의 강조색으로 칠합니다.
  5. 움직임 줄이기 설정을 켠 기기에서는 밀려 들어오는 효과 없이 즉시 바뀝니다.

<script>
/* ── 바꿔 쓸 지점 ②: 카드 데이터 배열 하나만 고치면 됩니다 ──
   c: 카드 강조색 / tag: 위쪽 작은 꼬리표 / big: 큰 숫자 / title: 한 줄 제목 / lines: 핵심 2~3줄 */
const VS_CARDS = [
  { c: "#D6336C", tag: "○○교육청 · 가상 예시", big: "2027", title: "신규 공무원 온보딩, 카드 6장이면 됩니다", lines: ["옆으로 넘겨 보세요"] },
  { c: "#E4572E", tag: "첫날", big: "D+0", title: "첫날은 세 가지만 끝내세요", lines: ["임용장 수령·복무 선서", "업무포털 계정 발급", "부서 인사, 자리·PC 배정"] },
  { c: "#0E8A86", tag: "첫 주", big: "D+7", title: "업무 흐름을 손에 익힙니다", lines: ["인수인계서 읽기", "전자결재 기안 실습 1건"] },
  { c: "#6B4FD8", tag: "문의", big: "2027", title: "막히면 내선 2027", lines: ["평일 09:00–18:00"] }
];

const frame = document.getElementById("vsFrame");
const bar = document.getElementById("vsBar");
let cur = 0;

// 카드와 진행 막대 만들기
const cards = VS_CARDS.map((d, i) => {
  const el = document.createElement("article");
  el.className = "vs-card";
  el.style.setProperty("--c", d.c);
  el.innerHTML = `<div class="vs-tag">${d.tag}</div><div class="vs-big">${d.big}</div>
    <h2 class="vs-title">${d.title}</h2><ul class="vs-lines">${d.lines.map(t => `<li>${t}</li>`).join("")}</ul>
    <div class="vs-foot"><span>가상 예시</span><span>${i + 1} / ${VS_CARDS.length}</span></div>`;
  frame.appendChild(el);
  bar.insertAdjacentHTML("beforeend", '<span class="vs-seg"><i></i></span>');
  return el;
});
const segs = [...bar.children];

// 현재 위치에 맞춰 past / now / next 상태 지정
function show(n) {
  cur = Math.max(0, Math.min(VS_CARDS.length - 1, n));
  cards.forEach((el, i) => {
    el.className = "vs-card " + (i < cur ? "past" : i === cur ? "now" : "next");
    el.style.transform = "";
  });
  segs.forEach((s, i) => s.classList.toggle("on", i <= cur));
}

// 스와이프(터치·마우스 드래그)와 탭: 왼쪽 1/3 탭은 이전, 나머지는 다음
let x0 = null, dx = 0;
frame.addEventListener("pointerdown", e => { x0 = e.clientX; dx = 0; frame.setPointerCapture(e.pointerId); });
frame.addEventListener("pointermove", e => {
  if (x0 === null) return;
  dx = e.clientX - x0;
  const nx = cards[cur + 1], pv = cards[cur - 1];
  if (dx < 0 && nx) { nx.style.transition = "none"; nx.style.transform = `translateX(calc(105% + ${dx}px))`; }
  if (dx > 0 && pv) { cards[cur].style.transition = "none"; cards[cur].style.transform = `translateX(${dx}px)`; }
});
frame.addEventListener("pointerup", e => {
  if (x0 === null) return;
  cards.forEach(el => el.style.transition = "");
  const w = frame.clientWidth;
  if (Math.abs(dx) < 6) show(e.clientX - frame.getBoundingClientRect().left < w / 3 ? cur - 1 : cur + 1);
  else show(Math.abs(dx) > w * 0.2 ? cur + (dx < 0 ? 1 : -1) : cur);
  x0 = null;
});

// 화살표 키
frame.addEventListener("keydown", e => {
  if (e.key === "ArrowRight") show(cur + 1);
  if (e.key === "ArrowLeft") show(cur - 1);
});

show(0);

  • 색·크기·속도는 :root의 --vs- 변수에 모여 있습니다. 카드별 강조색은 배열의 c.
  • 클래스는 모두 vs- 접두어라 기존 페이지에 붙여 넣어도 충돌하지 않습니다.

PPT로 옮기기

  1. 디자인 › 슬라이드 크기 › 사용자 지정에서 방향을 세로로, 너비 10.8cm × 높이 19.2cm(9:16)로 맞춥니다.
  2. 보기 › 슬라이드 마스터에서 위쪽 12pt 지점에 얇은 막대 6개(높이 0.1cm, 간격 0.1cm)를 회색으로 그려 둡니다. 각 슬라이드에서는 지난 칸과 현재 칸 위에 같은 크기의 색 막대를 덮어 진행을 표시합니다.
  3. 전환은 밀어내기, 효과 옵션 오른쪽에서, 기간 0.40초. 카드 스택 깊이는 PPT 기본 전환으로 완전히 재현되지 않으므로 갤러리 전환을 쓰거나, 밀어내기로 대신합니다.
  4. 각 슬라이드 배경색을 강조색의 9% 정도 옅은 색으로 바꾸고, 큰 숫자(96pt)와 제목(27pt)을 아래쪽에 모아 엄지가 닿는 위치에 둡니다.
  5. 메신저 공유는 파일 › 내보내기 › PDF로 저장하면 휴대폰에서 세로 한 장씩 넘겨 볼 수 있습니다.
