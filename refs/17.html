레퍼런스 #17 두 개의 심

처음 열면 두 심의 안쪽 나이테는 이미 있고, 그 바깥 공유 나이테만 한 겹씩 그려집니다(한 번만). 휴대폰에서는 단면이 위, 제목이 아래인 세로 배치로 바뀝니다.

가져갈 장치

과정을 펼치지 않고 단면 한 장으로 말하는 표지입니다. 다른 발표에도 옮겨 쓸 수 있는 장치만 골랐습니다.

단면 한 장으로 말하는 표지필수

둘이 하나가 되는 이야기를 단계별 그림 대신 잘린 면 하나로 보여 줍니다. 안쪽에는 따로 지낸 시간, 바깥에는 함께 지낼 시간이 겹쳐 있습니다. 응용: 두 학교 통합, 부서 통폐합, 지역 연계 사업.

나이테 = 연차별 성과 누적필수

바깥 공유 나이테 한 겹이 한 해입니다. 안쪽 장표에서는 나이테마다 연도와 성과를 붙여, 해가 갈수록 단면이 굵어지는 모습으로 누적을 보여 줍니다.

은은한 기관 색이 자연색으로 합쳐짐

심 가까이만 청록·황금 기운이 돌고 공유 나이테로 갈수록 같은 나무색이 됩니다. 기관 색을 범례 없이 쓰는 방법입니다.

흐름 설계 메모

계획안 순서를 단면의 안에서 바깥으로 읽히게 맞춥니다. 안쪽 장표에서는 단면을 화면 오른쪽 끝에 크게 반만 걸쳐 두고, 그 장표가 다루는 고리만 진하게 남깁니다.

계획안 구성단면의 자리안쪽 장표 아이디어
추진 배경두 개의 심두 심만 확대해 나란히. 심 옆에 각 기관의 근거 법령과 소관을 한 줄씩
현황 진단따로 자란 안쪽 나이테두 나이테 다발의 굵기·간격을 비교 막대처럼 읽게 함. 격차 항목(교사 자격, 운영 시간, 시설 기준, 재정)을 다발 바깥에 하나씩
추진 목표처음 둘을 감싼 나이테첫 공유 나이테 한 줄만 진하게, 그 위에 비전 문장 하나
세부 과제·선도 운영바깥 공유 나이테나이테 한 겹 = 한 해. 겹마다 연도와 그해 성과 지표(아래 예시)
기대 효과·지원 체계수피단면을 감싼 껍질에 지원 체계(예산, 인력, 협의체)를 둘러 적어 바깥에서 지켜 주는 장치로
2027선도기관 운영, 공통 지침 시범 적용
2028선도기관 확대, 교사 공동 연수
2029통합 기준 전면 적용 준비
2030성과 점검, 다음 나이테 계획

연도별 내용은 흐름을 보여 주기 위한 가상 예시입니다.

이렇게 쓰면 살아남

  • 표지와 안쪽 장표가 같은 단면을 공유하고 확대 위치만 바뀜
  • 마지막 장표는 다시 표지 단면으로 돌아와, 아직 비어 있는 바깥 테 자리를 "다음 해"로 남김

피할 것

  • 고리마다 지시선을 그어 설명하는 도감식 장표
  • 동심원 도형만 겹친 납작한 나이테. 결과 색 변화가 있어야 나무로 읽힘

PPT 이식
  1. 아래 두 단면 그림을 저장합니다(그림 위에서 오른쪽 클릭 → 다른 이름으로 저장, 휴대폰은 길게 누르기). 배경이 투명한 PNG입니다.
  2. 슬라이드 오른쪽 절반에 '통합 전'과 '완성' 두 장을 같은 크기·위치로 겹칩니다. 그림자는 그림에 들어 있습니다.
  3. '완성'에 나타내기 → '도형', 효과 옵션 '원형·바깥쪽', 1.5~2초. 공유 나이테가 바깥으로 퍼지듯 보입니다.
  4. 제목·라벨은 텍스트 상자로. 라벨은 둘 또는 셋까지만.
  5. 안쪽 장표: '완성'을 200~300%로 키워 오른쪽 끝에 반만 걸치고, 나머지 면에 내용을 놓습니다.

      let R=e0+(LATE[0]-e0)*lw,Gc=e1+(LATE[1]-e1)*lw,B=e2+(LATE[2]-e2)*lw;
      const dk=1-.13*bl*DARK[lo];R*=dk;Gc*=dk;B*=dk;
      // institution tint near piths
      const sel=sst(-.025,.025,d2-d1),fade=(1-sst(.12,.3,f))*.2;
      const t1=fade*sel,t2=fade*(1-sel);
      R+=(TEALT[0]-R)*t1+(GOLDT[0]-R)*t2;Gc+=(TEALT[1]-Gc)*t1+(GOLDT[1]-Gc)*t2;B+=(TEALT[2]-B)*t1+(GOLDT[2]-B)*t2;
      // medullary rays
      const ang=sel>.5?a1:a2;
      const ray=Math.pow(.5+.5*Math.sin(ang*150+fbm(x*6,y*6,2)*9),36)*sst(.03,.12,f);
      // fine grain + saw marks
      const g=.965+.07*vn(x*95,y*95)+.025*(vn(x*300,y*300)-.5);
      const saw=1+.016*Math.sin(Math.hypot(x-3.4,y+2.6)*90+vn(x*4,y*4)*3);
      // light: top-left, soft sheen
      const L=1+.05*(-x*.35-y*.6)+.075*Math.exp(-((x+.45)*(x+.45)+(y+.32)*(y+.32))/.1);
      let m=g*saw*L*(1+.05*ray);
      // pith
      const dp=Math.min(r1,r2);
      if(dp<.03){const pv=1-sst(.008,.022,dp);m*=1-.35*pv;R+=(150-R)*pv*.5;Gc+=(100-Gc)*pv*.5;B+=(60-B)*pv*.5}
      // pith checks
      [[P1,1.1],[P2,-.5]].forEach(([p,phi])=>{const ddx=x-p[0],ddy=y-p[1],rr_=Math.hypot(ddx,ddy);if(rr_<.07){const pd=Math.abs(-Math.sin(phi)*ddx+Math.cos(phi)*ddy);const wv=.0026*(1-rr_/.07);if(pd<wv)m*=.55+.3*pd/wv}});
      // included-bark seam where the trees met
      const seam=Math.abs(d1-d2);if(seam<.007&&f<.35)m*=1-.28*(1-seam/.007)*(1-sst(.27,.35,f));
      // radial checks from the edge
      const th=Math.atan2(y,x);
      for(const [ck,len] of CRACKS){const fs=REDGE-len;if(f>fs){let dt=th-ck-.006*Math.sin(f*40);dt=Math.atan2(Math.sin(dt),Math.cos(dt));
        const wid=.016*Math.pow((f-fs)/len,1.6)+.0006;const ad=Math.abs(dt);
        if(ad<wid){const c=1-ad/wid;m*=1-.5*Math.min(1,c*2.2);R+=(110-R)*c*.4;Gc+=(74-Gc)*c*.4;B+=(44-B)*c*.4}
        else if(dt>0&&ad<wid*1.9)m*=1+.05}}
      C[k*3]=R*m;C[k*3+1]=Gc*m;C[k*3+2]=B*m;
      // bark noise + light
      if(f>.2){const rid=1-Math.abs(2*vn(x*34+3,y*34)-1);const n2=.55*sst(.35,.85,rid)+.45*fbm(x*12,y*12,2);BN[k]=n2*255;
        const nx=x-(sel>.5?P1[0]:P2[0])*.6,ny=y;const nl=Math.hypot(nx,ny)||1;BL[k]=(-nx*.45-ny*.85)/nl}
    }}
  return{w,h,S,cx,cy,F,C,BN,BL};
}

let face,faceX,side,img;
function renderFace(Rc){
  const {w,h,S,F,C,BN,BL}=G,d=img.data,px=1.3/S,bw=.006+.05*Rc;
  for(let k=0,n=w*h;k<n;k++){const f=F[k],o=k*4;const dd=Rc-f;
    if(dd<-px){d[o+3]=0;continue}
    let R,Gc,B,a=dd<0?1+dd/px:1;
    if(dd<bw){const n2=BN[k]/255,t=dd/bw;const lgt=1+.22*BL[k]*(1-t*.4);
      const sh=.82+.18*sst(0,.35,t);
      R=(BARK_HI[0]+(BARK_LO[0]-BARK_HI[0])*n2)*lgt*sh;Gc=(BARK_HI[1]+(BARK_LO[1]-BARK_HI[1])*n2)*lgt*sh;B=(BARK_HI[2]+(BARK_LO[2]-BARK_HI[2])*n2)*lgt*sh;
      if(dd>bw-px*1.5){const c=.55;R+=(CAMB[0]-R)*c;Gc+=(CAMB[1]-Gc)*c;B+=(CAMB[2]-B)*c}}
    else if(dd<bw+.008){R=CAMB[0]*.98;Gc=CAMB[1]*.97;B=CAMB[2]*.95}
    else{const ao=1-.1*Math.exp(-(dd-bw-.008)/.018);R=C[k*3]*ao;Gc=C[k*3+1]*ao;B=C[k*3+2]*ao}
    d[o]=R;d[o+1]=Gc;d[o+2]=B;d[o+3]=a*255}
  face.getContext('2d').putImageData(img,0,0);
  const sc=side.getContext('2d');sc.globalCompositeOperation='source-over';sc.clearRect(0,0,w,h);sc.drawImage(face,0,0);
  sc.globalCompositeOperation='source-in';const gr=sc.createLinearGradient(0,0,0,h);gr.addColorStop(0,'#8A6443');gr.addColorStop(1,'#6A4A30');sc.fillStyle=gr;sc.fillRect(0,0,w,h);
}
function compose(c,ox,oy,S,scale){
  const th=S*.045;
  c.save();c.shadowColor='rgba(70,52,32,.26)';c.shadowBlur=S*.16*scale;c.shadowOffsetX=S*.04*scale;c.shadowOffsetY=S*.09*scale;
  c.drawImage(side,ox,oy+th);c.restore();
  c.save();c.shadowColor='rgba(60,42,24,.32)';c.shadowBlur=S*.025*scale;c.shadowOffsetY=S*.012*scale;c.drawImage(side,ox,oy+th);c.restore();
  for(let i=1;i<=3;i++)c.drawImage(side,ox,oy+th*i/4);
  c.drawImage(face,ox,oy);
}
