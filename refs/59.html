01가져갈 장치

장단 반복 타이포

같은 구절을 북 박자마다 한 번씩, 점점 크게 되풀이합니다. 앞의 둘은 외곽선 글자, 마지막 줄만 채운 글자라 제목이 먼저 읽힙니다.

다른 데 쓰기: “모인다 · 모인다 · 학부모가 모인다”(학부모 아카데미), “켜진다 · 켜진다 · 교실이 켜진다”(디지털 교실)

발 고정 원근 하강

호랑이 발끝을 기준점으로 잡고 크기를 0.26 → 1로 키우며 디딤 바위 두 곳을 거쳐 앞땅에 내려섭니다. 세 번의 착지가 세 단계(교육청 → 교육지원청 → 학교)입니다.

다른 데 쓰기: 위에서 아래로 내려가는 지원·배분 계획 전반(예산 배분, 순회 교사)

옛 그림 속 현대 사물 하나

민화 화풍은 먹 윤곽·맑은 평면 채색·한지 결로 지키고, 엉뚱함은 호랑이 목에 건 출입증 목걸이 하나에만 맡깁니다. 이 사물이 “범 = 우리 지원단”을 말해 줍니다.

지킬 것: 키치 사물은 한 개만. 둘이 되면 장난처럼 보입니다.

본문은 이 분위기를 따르되 정지 화면으로 둡니다. 모션은 표지 한 장뿐입니다. 어울리는 기존 요소(계열 C):

  • #55 원인 꽂힌 화살표: Ⅰ 현장 요청이 늦게 닿는 원인 → 해결
  • #34 허브 내비게이션 업무보고: Ⅱ 사흘 안 방문율 같은 핵심 수치
  • #44 분자 결합 추진체계 또는 #14 상세도 호출: Ⅳ 추진체계
  • #51 낱칸 시·군 지도: 지역별 요청·방문 건수

본문 장에 쓸 계열 값: 바탕 한지 #F7F0DF, 글자 먹 #211C18, 강조 짙은 주황 #C9611B 한 곳, 위계 농담은 석록(#2F6F5E → #A6D5C6) 한 색으로.

03재현 체크

  • 까치호랑이(작호도) 구도: 소나무 가지의 까치 + 아래의 호랑이, 까치는 기쁜 소식, 호랑이는 나쁜 기운을 막는 상징. 18~19세기 작호도에서 호랑이가 익살스러워진 흐름을 따랐습니다.
  • 민화 호랑이 관찰 디테일: 흰 테 → 노란 홍채 → 먹 눈동자의 동그란 겹눈, 정면 얼굴 + 옆모습 몸, 삐죽한 볼털, 흰 눈썹 털, 끝이 갈라지는 먹 줄무늬, 말려 올라간 꼬리와 고리 줄무늬, 발가락 선.
  • 소나무: 거북등처럼 갈라진 껍질 조각, 부채꼴로 퍼지는 솔잎 뭉치(방사선 + 옅은 석록 바탕).
  • 산: 청록 봉우리, 능선을 따라 찍은 태점(이끼 점), 짧은 준법 주름.
  • 소리북: 고수가 장단을 치는 북. 양쪽 가죽면 가장자리의 놋쇠 못, 북통 위 고리, 북통 쪽나무 이음, 북채.
  • 쓰지 않은 것: 실존 밴드·무용단·기관의 이름과 로고, 사람 모습, 영상 장면. 가사는 대목 이름 “범 내려온다”(화제 세로 글씨)만 썼습니다.

조사 출처

  • 월간 디자인: 430년 전 호작도(1592, 소나무 위 까치와 호랑이)
  • 민화의 매력: 18~19세기 작호도 호랑이의 익살
  • 한국민족문화대백과: 소리북(고장북) 재료·치는 자리
  • 트렌드: VistaPrint ‘Elemental Folk’ 2026(민속 문양을 깔끔한 현대 레이아웃에), G2 2026 키네틱 타이포그래피

PPT로 옮기기

  • 그림 구역(산·소나무·까치·호랑이)을 SVG로 저장해 삽입 → [그래픽 형식] 도형으로 변환. 호랑이는 그룹으로 묶어 둡니다.
  • 호랑이: 끝 위치에 두고 [애니메이션] 나타내기 + 이동 경로(사용자 지정 경로, 꺾임 3번) + 강조 ‘크게/작게’ 26% → 100%, 모두 ‘이전 효과와 함께’, 길이 2.4초.
  • 반복 구절: 1·2줄 ‘확대/축소’ 나타내기, 지연 0.25초 · 1.05초. 제목 줄은 처음부터 두고 1.85초에 ‘펄스’.
  • “얼씨구!”: 지연 2.6초 확대/축소 나타내기. 한지 결은 배경 서식의 질감 대신 옅은 한지 사진(투명도 85%)으로.

  var ff = $('bmFaceFur');
  var hg = el('g', {stroke:'var(--bm-ink)', 'stroke-width':'.9', opacity:'.6'}, ff);
  edgeHairs($('bmHead'), 6, 6, hg);
  var cg = el('g', {stroke:'var(--bm-tiger3)', 'stroke-width':'1', opacity:'.7'}, ff);
  for(var k=0;k<46;k++){
    var side = k%2 ? 1 : -1, a = (-0.9+rnd()*1.6), r0 = 40+rnd()*36;
    var x = 106+side*(30+rnd()*48), y = 120+rnd()*92;
    el('path', {d:'M'+x.toFixed(1)+','+y.toFixed(1)+' l'+(side*(4+rnd()*4)).toFixed(1)+','+(2+rnd()*4).toFixed(1)}, cg);
  }
  var tb = $('bmTailBands');
  [[440,128,456,120],[444,96,460,94],[426,66,444,58],[426,40,440,28]].forEach(function(b){ el('path', {d:'M'+(b[0]-10)+','+(b[1]+2)+' L'+b[2]+','+b[3]}, tb); });

  /* ── 장단 연출 ──
     북 세 번(덩·덩·덩)마다 반복 구절이 하나씩 찍히고, 호랑이가 산 → 바위 → 바위 → 앞땅으로 한 번씩 내려온다.
     발 위치(ANCHOR)를 기준점으로 크기를 키워 멀리서 가까이 오는 원근을 만든다. */
  var tiger = $('bmTiger'), ripple = $('bmRipple'), drum = $('bmDrumBody');
  var lines = root.querySelectorAll('[data-beat]'), chu = root.querySelector('.bm-chu');
  var ANCHOR = [230, 356];
  var STOPS = [ [1186,206,.26], [1362,374,.42], [1136,456,.6], [1190,826,1] ];
  var BEATS = [.25, 1.05, 1.85];   // 북 치는 시각(초)
  var HOP = .62, END = 3.0;
  function ease(t){ return t<.5 ? 2*t*t : 1-Math.pow(-2*t+2,2)/2; }
  function setTiger(x,y,s){ tiger.setAttribute('transform','translate('+(x-ANCHOR[0]*s).toFixed(1)+','+(y-ANCHOR[1]*s).toFixed(1)+') scale('+s.toFixed(3)+')'); }
  function render(t){
    // 호랑이
    var x=STOPS[0][0], y=STOPS[0][1], s=STOPS[0][2];
    for(var i=0;i<3;i++){
      var t0 = BEATS[i]+.05, u = (t-t0)/HOP;
      if(u>=1){ x=STOPS[i+1][0]; y=STOPS[i+1][1]; s=STOPS[i+1][2]; }
      else if(u>0){ var e=ease(u), a=STOPS[i], b=STOPS[i+1]; x=a[0]+(b[0]-a[0])*e; y=a[1]+(b[1]-a[1])*e - Math.sin(Math.PI*u)*(26+22*i); s=a[2]+(b[2]-a[2])*e; break; }
    }
    setTiger(x,y,s);
    // 반복 구절: 북 치는 순간 살짝 크게 찍혔다 자리 잡음
    var hit = 0;
    for(var j=0;j<lines.length;j++){
      var v = (t-BEATS[j])/.18;
      if(j===lines.length-1){   // 제목 줄은 처음부터 보이고, 셋째 박에 한 번 크게 울린다
        lines[j].style.opacity=1; lines[j].style.transform='scale('+(v>0&&v<1.6 ? 1+.07*Math.sin(Math.PI*v/1.6) : 1).toFixed(3)+')';
      }
      else if(v<0){ lines[j].style.opacity=0; lines[j].style.transform='scale(1.12)'; }
      else { var c=Math.min(1,v); lines[j].style.opacity=1; lines[j].style.transform='scale('+(1.12-.12*ease(c)).toFixed(3)+')'; }
      var dv = t-BEATS[j]; if(dv>=0 && dv<.3) hit = Math.max(hit, 1-dv/.3);
    }
    ripple.setAttribute('opacity', hit.toFixed(2));
    drum.setAttribute('transform', 'translate(97,68) scale('+(1+.035*hit).toFixed(3)+') translate(-97,-68)');
    // 추임새: 착지 뒤에
    var w = (t-2.55)/.25;
    chu.style.opacity = w<=0 ? 0 : Math.min(1,w);
    chu.style.transform = 'rotate(-7deg) scale('+(w<=0?1.2:(1.2-.2*Math.min(1,w))).toFixed(3)+')';
  }
  var raf=0;
  function play(){
    cancelAnimationFrame(raf);
    if(window.matchMedia && matchMedia('(prefers-reduced-motion: reduce)').matches){ render(END); return; }
    var start = null;
    function step(now){ if(start===null) start=now; var t=(now-start)/1000; render(Math.min(t,END)); if(t<END) raf=requestAnimationFrame(step); }
    raf = requestAnimationFrame(step);
  }
  render(END);   // 기본은 끝 화면(정지 화면에서도 모든 정보가 남음)
  root.bmPlay = play; root.bmSeek = function(t){ cancelAnimationFrame(raf); render(t); };
  // 폰트가 준비된 뒤 한 번 재생
  (document.fonts && document.fonts.ready ? document.fonts.ready : Promise.resolve()).then(function(){ setTimeout(play, 150); });
})();
