낱칸 시·군 지도

시·군 타일 안에 학교를 한 칸씩 쌓아, 문제 학교가 어디에 몰렸는지와 몇 교인지를 같은 그림에서 읽게 한 본문 장표입니다. 가상 예시입니다.

계열 값 바꿔 보기

구조

시·군을 같은 크기의 타일로 바꿔 실제 위치에 가깝게 놓고(타일 격자 지도), 각 타일 안에 학교 1교를 작은 칸 하나로 쌓았습니다. 칸은 아래부터 보강이 남은 학교를 먼저 채우므로 진한 칸의 양이 미완료 학교 수, 칸 더미의 높이가 그 시·군의 전체 학교 수입니다. 오른쪽 열은 지도에서 보인 쏠림을 숫자로 확정합니다. 핵심 수치, 권역 몫 막대, 묶음별 비율 막대가 위에서 아래로 이어집니다.

가져갈 장치: 칸 하나 = 학교 1교. 면적을 크게 차지하는 군 지역이 부풀어 보이는 일반 단계구분도와 달리 타일 크기가 모두 같고, 수량은 칸 개수로만 셉니다. 비율 지도는 학교 수가 적은 군의 70%와 큰 시의 19%를 같은 무게로 보여 주지만, 이 장표는 "몇 교 중 몇 교"를 그대로 보여 줍니다.

두 번째 장치: 권역 윤곽은 타일 사이 틈을 지납니다. 강조색은 이 윤곽과 오른쪽 몫 막대, 한 곳에만 씁니다. 같은 뜻에만 쓰므로 지도와 숫자가 한눈에 이어집니다.

응용 예

  • 석면 잔존 학교: 진한 칸 = 석면 건축자재가 남은 학교, 권역 = 2027 제거 집중 지역
  • 원거리 통학: 칸 = 통학 거리 3km 넘는 학생 10명, 권역 = 통학버스 신규 노선 대상
  • 늘봄 대기: 칸 = 학교 1교, 진한 칸 = 대기 인원이 있는 학교, 권역 = 거점형 늘봄센터 설치 후보

(function(){

  // 격자 치수(가상 화면 1600×900 기준)

  const tx = c => X0 + c*PX, ty = r => Y0 + r*PY;
  const sum = (a,k) => a.reduce((s,x)=>s+x[k],0);
  const Z = R.filter(x=>x.g), N = R.filter(x=>!x.g);
  const T = sum(R,'t'), O = sum(R,'o'), zT = sum(Z,'t'), zO = sum(Z,'o'), nT = sum(N,'t'), nO = sum(N,'o');

  // 시·군 타일: 한 칸 = 학교 1교, 아래부터 미완료 학교를 먼저 채운다(높이 = 학교 수, 진한 칸 = 미완료)

      `<text class="ns-n" x="${X+TW-12}" y="${Y+28}" text-anchor="end"><tspan class="ns-nb" style="font-size:16px">${x.o}</tspan>/${x.t}</text>`+
      q+
      `<text class="ns-n" x="${X+TW-10}" y="${base}" text-anchor="end">${Math.round(x.o/x.t*100)}%</text>`);
  });

  // 강조 권역 윤곽(타일 사이 틈의 가운데를 지난다) — 강조색은 이 권역 한 곳에만

  });
  rows.forEach((r,i)=>{

  });
  rows.forEach((r,i)=>{ g += `<text class="ns-n" x="1520" y="${592+i*38+18}" text-anchor="end">${r.f}</text>`; });
  s += inD('1.10', g +
    `<text class="ns-s" x="${RX}" y="772">미완료 = 내진성능평가 결과 보강이 필요한 건물이 1동 이상 남은 학교</text>`+

  6. 오른쪽 막대: 몫 막대 전체 너비 12.2cm = 148교 → 61교는 5.03cm. 비율 막대는 100% = 6.35cm로 66.3% → 4.21cm, 20.2% → 1.28cm, 28.4% → 1.80cm. 막대 차트 개체를 쓰면 축 최소값을 0으로 고정합니다.
  7. [애니메이션] 나타내기 → 페이드. 타일 14개는 첫 개체만 "클릭할 때", 나머지는 "이전 효과와 함께" + 지연 0.05초씩 증가, 길이 0.35초. 권역 윤곽 0.70초, 범례 0.75초, 오른쪽 블록 0.80·0.95·1.10초(모두 "이전 효과와 함께").
