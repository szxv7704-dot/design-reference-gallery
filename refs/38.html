○○시 폭염 대응 종합대책(안) · Ⅲ-2. 무더위쉼터 재배치

쉼터 6곳을 옮기고 4곳을 더하면, 열섬 고위험 구역 92%가 걸어서 5분 안에 닿는다

4/4 · 4곳 신설

도보 5분(약 300m) 안에 쉼터가 있는 열섬 고위험 구역

92%
열섬 강도(낮음→매우 높음)
솟은 칸 = 아직 쉼터가 먼 곳
현행 쉼터와 도보 5분 범위
옮긴 자리 · ◆ 신설
가상 예시 · 1칸 ≈ 300m

MOTION무엇이 움직이고, 왜 움직이나

같은 육각 지도 위에서 색은 열섬 강도, 높이는 쉼터 공백을 맡는다. 처음엔 모든 열섬이 솟아 있고, 쉼터가 떨어지고 옮겨지고 더해질 때마다 도보 5분 범위 안의 칸만 물결처럼 내려앉는다. 끝까지 솟아 있는 몇 칸이 '아직 남은 공백'이라는 결론을 말로 하지 않아도 보여 준다.

정보 구조

현행 → 대안 1(재배치) → 대안 2(신설)를 한 바닥에서 비교한다. 지도를 바꿔 끼우지 않고 같은 지형이 변형되므로, 무엇이 달라졌는지가 칸 단위로 남는다. 옮긴 쉼터는 이전 자리(점선 고리)와 호 경로를 최종 화면에 남겨 '어디서 어디로'가 정지 화면에서도 읽힌다.

응용 예

  • CCTV·가로등 재배치: 높이 = 사각지대, 장치를 옮기면 지형이 꺼짐
  • 공공 와이파이·전기차 충전소 확충: 수요 강도 색 + 미설치 공백 높이
  • 지점·매장 통폐합 보고: 닫는 지점은 솟고, 옮긴 지점 주변은 꺼지는 양방향 변형

HTML가져다 쓰기

아래 코드를 HTML 파일 본문에 그대로 붙여 넣으면 장표·버튼·애니메이션이 동작한다(글꼴은 <head>에 Google Fonts 링크를 넣거나 대체 글꼴로 표시). 외부 라이브러리 없음.


    
바꿔 쓸 지점
    
      
  • MAP 문자열 배열: 한 글자가 한 칸. 0~3은 강도, w는 계산에서 빼는 칸(하천·녹지).
    • 
      
  • KEEP·MOVES·ADD: 유지·이전·신설 쉼터 좌표. 비율은 자동 계산되므로 제목의 숫자만 맞춰 고치면 된다.
    • 
      
  • REACH: 도달 범위(칸 수). HIGH: 비율 계산에 넣을 강도.
    • 
      
  • STEPS: 단계 표시 문구와 오른쪽 막대 이름. HEAT: 강도별 윗면·옆면 색.
    • 
      
  • CSS 변수 --hx-teal·--hx-paper·--hx-sans로 기관 색과 글꼴 교체.
    • 
    

  


  

    
POWERPOINTPPT로 옮기기

    
칸이 264개면 PPT에서 무겁다. 12×7 격자(84칸)로 줄여 만들고, 높이 변화는 모핑, 쉼터 등장은 슬라이드 안 애니메이션으로 나눈다.

    

      
순서대상 개체방법 · 애니메이션 이름효과 옵션시작재생 시간지연

      
        
준비칸 1개 = 윗면 육각형 + 아래 짙은 육각형삽입 › 도형 › 육각형, 회전 90°. 짙은 옆면색 복제를 같은 자리에 두고 맨 뒤로. 윗면을 위로 올린 만큼 아래 도형이 옆면처럼 드러남윗면 흰 윤곽 0.75pt———

        
이름 짓기모든 윗면·쉼터·막대홈 › 정렬 › 선택 창에서 !!H0705(열·행), !!P01, !!BAR2처럼 이름 앞에 !!. 슬라이드끼리 같은 이름이면 모핑이 같은 개체로 짝지음————

        
① → ② 지형 솟기윗면 육각형슬라이드 ①(평면) 복제 → ②에서 강도만큼 윗면을 위로(1단계 = 0.15cm). 전환 › 모핑개체클릭할 때1.50초—

        
② 안: 현행 쉼터쉼터 표식 18개나타내기 › 바운드—첫 개체 클릭할 때, 나머지 이전 효과 다음에0.50초0.05초씩

        
② 안: 도보 5분 원범위 원나타내기 › 확대/축소개체 가운데이전 효과와 함께0.40초0.10초

        
② → ③ 칸 꺼짐덮인 칸 윗면, 막대·숫자③에서 덮인 칸 윗면을 아래 도형 자리로 내리고 막대 길이·숫자 변경. 전환 › 모핑개체(숫자는 '문자'로 하면 자리별로 교차)클릭할 때1.25초—

        
③ → ④ 6곳 옮기기옮길 쉼터 6개④에서 같은 이름 표식을 새 자리로 옮기면 모핑이 이동시킴. 호 모양 경로가 필요하면 대신 이동 경로 › 호 또는 사용자 지정 경로경로 › 방향 반전으로 휘는 쪽 조정클릭할 때1.00초개체마다 0.1초

        
④ 안: 이전 자리·호점선 고리, 점선 호나타내기 › 닦아내기왼쪽에서(호 방향에 맞춤)이전 효과와 함께0.70초—

        
④ → ⑤ 4곳 신설◆ 표식 4개 → 칸 꺼짐⑤ 안에서 ◆ 나타내기 › 바운드, 이어서 ⑥으로 모핑해 주변 칸 꺼짐—클릭할 때0.50초 / 1.25초0.05초씩

      
    

    
안 되는 동작과 근사법
    
      
  • 물결처럼 번지는 꺼짐(가까운 칸부터): 모핑은 한꺼번에 움직인다. 꺼질 칸을 거리별 2~3묶음으로 나눠 슬라이드를 한 장 더 넣거나, 슬라이드 안에서 강조 › 이동 경로 › 선(아래로)을 묶음마다 지연 0.15초씩 준다.
    • 
      
  • 숫자 세기(32→80→92): 숫자 보간은 불가. 숫자 상자에 끝내기 › 밝기 변화, 새 숫자에 나타내기 › 올라오기를 0.3초로 겹친다.
    • 
      
  • 표식이 호를 따라 날며 커졌다 작아짐: 이동 경로 › 호 + 강조 › 크게/작게(125%, 자동 반전)를 이전 효과와 함께.

가져갈 장치
높이 = 남은 문제. 색은 원래 속성, 높이는 해결되지 않은 정도로 나눠 두면 대안을 적용할수록 지형이 평평해지고, 남은 봉우리가 곧 다음 과제가 된다.
