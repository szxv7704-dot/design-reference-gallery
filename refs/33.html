레퍼런스 #33 쪼개지는 예산 사각형

가상 예시 · 단위 억 원

1 · 총액 — 큰 사각형 하나

2027 본예산 전체를 칸 구분 없는 한 덩어리로 보여 준다. 화면에 큰 숫자는 5.2조 하나뿐이다.

말할 문장: “올해 우리 청이 쓰는 돈은 이 사각형 하나입니다.”

2 · 분야 — 같은 사각형이 갈라진다

덩어리에 틈이 벌어지며 분야별 색이 들어온다. 면적이 곧 금액이라 인건비 60%가 한눈에 보인다.

말할 문장: “이 중 60%는 이미 정해진 인건비입니다.”

3 · 사업 — 교육사업비만 확대

교육사업비 칸이 화면을 채우도록 커지고, 나머지 분야는 왼쪽 띠로 물러나 맥락만 남긴다. 그 안에서 주요 사업 다섯 개가 나뉜다.

말할 문장: “정책으로 움직일 수 있는 6,760억은 이렇게 나뉩니다.”

4 · 결론 — 증액분으로 다시 쪼갠다

면적 기준을 편성액에서 전년 대비 증액분으로 바꾼다. 학교로 직접 가는 칸이 왼쪽에 모여 검은 머리글 아래 묶이고, 제목 문장에 형광 표시가 칠해진다.

말할 문장: “늘어난 1,800억 중 62%는 학교로 바로 갑니다.”

쪼개지는 예산 사각형

장표는 그대로 두고 도형 하나가 총액 → 분야 → 사업 → 결론 순으로 모양을 바꾼다. 위 장표를 스크롤하거나 → 키, 장표 클릭, 아래 단계 버튼으로 넘겨 볼 수 있다. 기관명과 모든 수치는 가상 예시다.

가져갈 장치

계속 쪼개지는 한 도형

새 차트로 갈아끼우지 않고 같은 사각형을 총액 → 분야 → 사업으로 쪼갠다. 청중은 방금 본 칸이 어디로 갔는지 따라가므로 “이 돈이 저 돈의 일부”라는 포함 관계를 설명 없이 이해한다.

단계마다 큰 숫자 하나

왼쪽 큰 숫자 자리는 하나만 둔다. 5.2조 → 60% → 6,760억 → 62%. 칸 안의 금액은 작게 두고, 발표자가 말할 숫자만 크게 남긴다.

기준을 바꿔 다시 쪼개기

마지막 단계는 같은 칸들의 면적 기준을 편성액에서 증액분으로 바꾼다. 크던 인건비 칸이 작아지고 학교운영비가 커지는 변화 자체가 결론의 근거가 된다.

동작 설명

장표 안 도형은 분야 5칸과 교육사업비 하위 사업 5칸, 모두 10개다. 단계가 바뀔 때 이 10개는 새로 만들어지지 않고 위치·크기·색만 바뀐다. 1단계에서는 간격 0, 같은 색이라 하나로 보이고, 하위 사업 칸은 교육사업비 칸 안에 투명하게 숨어 있다가 3단계에서 드러난다. 그래서 확대가 “안을 들여다보는” 동작으로 읽힌다.

제목은 처음부터 결론 문장이다. 청중은 결론을 먼저 읽고, 이어지는 세 번의 쪼개짐을 그 근거로 본다.

  • 세입 구성 설명: 총세입 → 교부금·전입금·자체수입 → 교부금 내 보통/특별 교부금.
  • 학교 기본운영비 배분: 전체 학교운영비 → 학교급별 → 한 학교의 항목별 사용처.
  • 정원·인력 현황: 전체 정원 → 직렬별 → 결원이 몰린 직렬 확대 → “충원 필요 인원” 결론.

    } else if(step===1){ // ② 분야별로 갈라짐
      bySec.forEach(q=>{ const r=inset(q,g); put(q.ref,r,{bg:q.ref.d.color, val:fmt(q.ref.d.amount)+' · '+pct(q.ref.d.amount/total)}); if(q.ref===zc) zr=r; });
      kidsIn(zr,0);
    } else if(step===2){ // ③ 확대 분야가 화면을 채우고 나머지는 왼쪽 띠로
      const sW = W*0.17, others = secs.filter(c=>c!==zc), ot = sum(others.map(c=>c.d),'amount');
      let cy = 0;
      others.forEach(c=>{ const h=H*c.d.amount/ot; put(c, inset({x:0,y:cy,w:sW,h},g), {bg:mix(c.d.color,bg,.62), fg:cssVar('--bm-sub')}); cy+=h; });
      zr = inset({x:sW,y:0,w:W-sW,h:H},g);
      put(zc, zr, {bg:zoom.color, lab:false});
      kidsIn({x:zr.x-g/2,y:zr.y-g/2,w:zr.w+g,h:zr.h+g},1);
    } else { // ④ 면적 기준을 증액분으로 바꾸고 학교 직접분을 왼쪽에 묶음
      const hh = Math.max(26, H*0.13), dW = W*directInc/incTotal;
      const A = secs.filter(c=>c.d.direct), B = secs.filter(c=>!c.d.direct);
      squarify(A.map(c=>({v:c.d.inc,ref:c})), 0,hh,dW,H-hh).forEach(q=>put(q.ref, inset(q,g), {bg:q.ref.d.color, val:'+'+fmt(q.ref.d.inc)}));
      squarify(B.map(c=>({v:c.d.inc,ref:c})), dW,hh,W-dW,H-hh).forEach(q=>{ const r=inset(q,g); put(q.ref, r, {bg:mix(q.ref.d.color,bg,.62), fg:cssVar('--bm-sub'), val:'+'+fmt(q.ref.d.inc)}); if(q.ref===zc) zr=r; });
      kidsIn(zr,0);
      const ga = inset({x:0,y:0,w:dW,h:hh},g), gb = inset({x:dW,y:0,w:W-dW,h:hh},g);
      Object.assign(grpA.style,{left:ga.x+'px',top:ga.y+'px',width:ga.w+'px',height:ga.h+'px'});
      Object.assign(grpB.style,{left:gb.x+'px',top:gb.y+'px',width:gb.w+'px',height:gb.h+'px'});
    }
    if(step!==3){ [grpA,grpB].forEach(e=>Object.assign(e.style,{left:'0px',top:'0px',width:W+'px',height:'0px'})); }
    totalLab.style.opacity = step===0 ? 1 : 0;
    return L;
  }

  let step = 0;
  function render(instant){
    if(instant) root.classList.add('bm-instant');
    const L = layout(step);
    const fs = parseFloat(getComputedStyle(cells[0].lab).fontSize) || 12;
    L.forEach((o,c)=>{
      const s = c.el.style;
      s.left=o.x+'px'; s.top=o.y+'px'; s.width=o.w+'px'; s.height=o.h+'px';
      s.backgroundColor=o.bg; s.opacity=o.op; s.color=o.fg || textOn(o.bg);
      s.zIndex = c.kind==='kid' ? 2 : 1;
      c.val.textContent = o.val;
      const fits = o.lab && o.op>0 && o.w>=fs*4.2 && o.h>=fs*2;   // 칸이 작으면 이름표를 숨겨 겹침 방지
      c.lab.style.opacity = fits ? 1 : 0;
      c.val.style.display = (o.val && o.h>=fs*3.4) ? 'block' : 'none';
    });
    const S = STEPS[step];
    $('.bm-kicker').textContent = S.kicker;
    $('.bm-big').textContent = S.big;
    $('.bm-cap').textContent = S.cap;
    $('.bm-step-label').textContent = (step+1)+'/'+STEPS.length+' · '+S.dot;
    stage.setAttribute('aria-label', S.kicker+' '+S.big+'. '+S.cap);
    root.dataset.step = step;
    $('.bm-prev').disabled = step===0;
    $('.bm-next').disabled = step===STEPS.length-1;
    dots.forEach((d,i)=> i===step ? d.setAttribute('aria-current','step') : d.removeAttribute('aria-current'));
    if(instant){ void root.offsetWidth; requestAnimationFrame(()=>root.classList.remove('bm-instant')); }
  }

  const dots = STEPS.map((S,i)=>{ const b=document.createElement('button'); b.type='button'; b.className='bm-dot'; b.textContent=S.dot; b.addEventListener('click',()=>go(i)); $('.bm-dots').appendChild(b); return b; });
  function go(n, source){
    n = Math.max(0, Math.min(STEPS.length-1, n));
    if(n===step) return;
    step = n; render(false);
    root.dispatchEvent(new CustomEvent('bm:step',{detail:{step:n, source:source||'control'}}));
  }
  root.bmGo = go;   // 스크롤 연동 등 바깥에서 root.bmGo(단계번호) 로 호출
  $('.bm-prev').addEventListener('click',()=>go(step-1));
  $('.bm-next').addEventListener('click',()=>go(step+1));
  stage.addEventListener('click',()=>go(step+1));
  document.addEventListener('keydown',e=>{   // 발표 중 → ← 키 (장표가 화면에 보일 때만)
    if(e.target.closest && e.target.closest('input,textarea,select,[contenteditable]')) return;
    const r = root.getBoundingClientRect(); if(r.bottom<0 || r.top>innerHeight) return;
    if(e.key==='ArrowRight'||e.key==='PageDown'){ e.preventDefault(); go(step+1); }
    if(e.key==='ArrowLeft'||e.key==='PageUp'){ e.preventDefault(); go(step-1); }
  });
  render(true);
  new ResizeObserver(()=>render(true)).observe(stage);
  if(document.fonts) document.fonts.ready.then(()=>render(true));
})();
</script>
바꿔 쓸 지점
  1. BM_ITEMS 배열: 분야 이름·편성액·증액·색·학교직접 여부. 숫자와 제목 문장은 여기서 자동 계산된다.
  2. zoom:true를 다른 분야로 옮기고 그 안에 children을 넣으면 3단계 확대 대상이 바뀐다.
  3. BM_TEXT: 기관명·연도·묶음 이름(“학교로 직접”/“교육청 집행”).
  4. STEPS의 cap: 단계별 한 줄 설명.
  5. CSS 변수 --bm-dur(변형 시간), --bm-mark(형광 색). 스크롤 연동은 root.bmGo(단계)를 호출하면 된다.

PPT로 옮기기

슬라이드 4장을 만들고 2~4장에 모핑 전환을 건다. 핵심은 네 장 모두에서 같은 도형에 같은 이름을 붙이는 것이다. 이름 앞에 !!를 붙이면 PowerPoint가 모양·글자가 달라도 같은 도형으로 짝지어 변형한다.

  1. 1장: 사각형 5개를 트리맵처럼 빈틈없이 배치하고 모두 진한 남색(#1D2B2A)으로 칠한다. 홈 → 정렬 → 선택 창(Alt+F10)에서 이름을 !!인건비, !!학교운영비, !!교육사업비, !!시설비, !!기타로 바꾼다.
  2. 같은 장에서 교육사업비 칸 안에 하위 사업 사각형 5개(!!기초학력 등)를 작게 넣고 도형 서식 → 채우기 투명도 100%로 숨긴다. 큰 숫자 텍스트 상자는 !!큰숫자, 제목 뒤 형광 사각형은 !!형광(너비 0.1cm)으로 둔다.
  3. 1장을 슬라이드 복제(Ctrl+D)해 2장을 만든다. 칸 사이 간격을 벌리고 분야 색을 칠한다. 큰 숫자를 “60%”로 고친다.
  4. 다시 복제해 3장: !!교육사업비를 오른쪽 전체로 키우고 나머지는 왼쪽 띠로 줄이며 흐린 색으로 바꾼다. 하위 사업 5개는 교육사업비 칸을 채우도록 키우고 투명도를 0%로 되돌린다.
  5. 다시 복제해 4장: 분야 칸 크기를 증액분 비율로 다시 잡고, 학교 직접분 두 칸을 왼쪽에 모은다. 하위 사업은 교육사업비 칸 안으로 줄여 투명도 100%. !!형광을 제목 길이만큼 늘린다.
  6. 2~4장을 선택하고 전환 → 모핑, 효과 옵션 → 개체, 기간 00.70초. 발표 중에는 클릭이나 → 키로 넘긴다.
