# 분류 기준

갤러리는 **참고용 장표 모음**이다. 여기서 덱을 만들거나 발표를 진행하지 않는다.
첫 화면(`index.html`)과 글 목록(`catalog.md`)은 `scripts/site.py`가 `data/rounds.json`에서 만든다.

## 1. 분위기 여덟 (가장 큰 묶음)

| 계열 | 이름 |
|---|---|
| A | 픽셀 게임 |
| B | 미니멀 스튜디오 |
| C | 경쾌한 놀이 오브젝트 |
| D | 인쇄·종이 에디토리얼 |
| E | 자연 재질 |
| F | 관측·중계 인포그래픽 |
| G | 어두운 콘셉트 |
| H | 전통 공예·문양 |

- 표지 · 목차·간지·맺음 키트는 분위기가 하나(`family`)다.
- 본문은 대부분 **공용**이다: 구조만 만들고 색 · 글꼴은 변수(`--ds-*`)로 받아, 여러 분위기에 갈아 끼운다(`families`, 넷 이상이면 공용으로 센다). 한두 분위기에만 맞는 본문은 그 분위기의 전용 본문이다.

## 2. 표지 하나 = 덱 한 벌

표지가 분위기를 정하고 본문은 그 표지를 따른다. 그래서 덱의 단위는 분위기가 아니라 **표지**다(`deck.html?cover=17`, 순서는 `data/decks.json`).

`표지 → 목차·간지·맺음(그 분위기의 키트) → 본문 → 그 분위기 전용 본문`

- **본문**은 모양마다 하나씩 고른 대표(`scripts/site.py`의 `REPS`)다. 자리 순서로 놓는다: 배경 · 현황 → 목표 · 지표 → 세부 과제 → 추진 체계 → 일정 · 예산. 대표를 바꾸려면 `REPS`의 번호를 바꾼다.
- 본문에는 **그 표지의 색 · 글꼴**을 입힌다. 표지마다 다섯 값(바탕 · 글자 · 위계 기준색 · 강조색 · 글꼴 셋)을 `data/covers.json`에 손으로 적었고, `scripts/light.py`가 `--ds-*` 변수로 풀어 `light/slide.js`에 넣는다. `light/번호.html?slide=c17`이 장표만 남기고 그 값을 입힌다.
- **어두운 표지도 본문은 밝은 바탕**이다. 공용 본문이 밝은 바탕 기준으로 만들어졌기 때문이고, 실제 덱에서도 흔한 방식이다(표지의 강조색과 글꼴로 이어 준다).
- 새 표지를 넣으면 `data/covers.json`에 그 표지의 값을 적는다(없으면 본문이 중립 색으로 나오고 `site.py`가 알려 준다).

## 3. 본문의 모양

본문 장표에는 '내용의 모양'을 하나씩 붙였다(`data/triage.json`의 `pattern`, 판정은 `scripts/triage.py`). 같은 자리 안에서 모양으로 다시 묶는다.

| 묶음 | 모양 |
|---|---|
| 글 | 한 문장 · 항목 · 용어 정의 · 인용 |
| 관계 | 순서·단계 · 둘 비교 · 전→후 · 묶음·분류 · 체계 |
| 수 | 큰 숫자 · 막대 비교 · 추이 · 구성비 · 표 |
| 시간 | 일정 |
| 그림 | 사진+글 · 화면 짚기 |
| 청중에게 | 질문 · 할 일 |

기존 본문 장표는 관계 · 수 · 시간 쪽에 몰려 있고, 글 · 그림 · 청중에게 쪽은 없다(덱 키트 부품에만 있다).

## 4. 그 밖

- **발표 틀**: 넘기는 덱이 아니라 자체 진행 방식(허브 · 스크롤 · 탐험 지도).
- **인쇄 · 홍보물**: 포스터 · 리플렛 · 소식지.
- **덱에 그대로 넣기 어려운 본문**: 눌러서 조작하는 것, 재질 질감이 강한 것(`deck_ok: false` 또는 어울리는 분위기가 없는 것).
- **숨김**: 제작 기준(`criteria.md` 6)에 걸린 것. 목록에 번호만 적는다.

## 5. AI가 읽을 수 있게

- 첫 화면은 내용이 모두 HTML 안에 들어 있다(스크립트 없이 글로 읽힌다).
- `catalog.md`(차례) · `catalog/A.md`~`H.md`(분위기별) · `catalog/body.md`(공용 본문, 모양별) · `catalog/etc.md`: 장표마다 쓰임 · 분위기 · 가져갈 장치 · 설명 · 색 · 글꼴 · 주소를 적은 글 목록. 한 파일이 60KB를 넘지 않게 쪼갰다.
- `light/번호.html`: 글꼴 · 그림을 박지 않은 가벼운 판(평균 50KB, `scripts/light.py`). 원본 `refs/번호.html`은 인터넷 없이 도는 완성본이라 평균 800KB다.

## 6. 덱 키트

`kit/`은 분위기별 뼈대(표지 · 목차 · 간지 · 맺음)와 공용 부품, 예시 덱 둘(성과 공유회 · 계획안 발표)이다. 갤러리의 곁가지이고, 정의는 `data/patterns.json` · `data/flows.json`에 있다.
