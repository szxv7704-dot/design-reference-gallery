# 제작 기준

새 장표 · 키트를 만들 때 이 문서를 먼저 따른다. 분류 기준은 [분류 기준](patterns.md)에 있다.
대화에서 "이거 안 돼", "이거 밤티야"라고 짚은 것은 **6. 피할 것**에 계속 더한다.

## 1. 무엇인가
- 이 갤러리는 **발표 덱을 만들 때 참고하는 장표 모음**이다. 여기서 덱을 만들거나 발표를 진행하지 않는다.
- 장표는 16:9 발표용이다. 청중 앞 큰 화면에서 넘기며 말하므로 **움직임은 장점**이다. PPT 이식 · 흑백 인쇄 · 결재 양식은 기준이 아니다.
- 사람과 채팅 AI가 함께 읽는다. AI가 주소만으로 읽을 수 있게 글 목록(`catalog.md`)과 가벼운 코드(`light/`)를 함께 낸다.

## 2. 묶는 법
분위기 여덟으로 묶고, 분위기마다 `표지 → 목차·간지·맺음 → 본문` 순서로 한 덱처럼 본다. 자세한 기준은 [분류 기준](patterns.md).

## 3. 새 장표를 넣을 때
- `data/rounds.json` 항목에 `role` · `family`(또는 `families`) · `section` · `motion` · `takeaway`를 적는다.
- 본문은 `scripts/triage.py`의 `BODY`에 모양을 적는다.
- `python3 scripts/light.py && python3 scripts/triage.py && python3 scripts/site.py`로 가벼운 판 · 목록 · 첫 화면을 다시 만든다.

## 4. 그림
- **SVG(또는 CSS · 캔버스로 흉내 낸 SVG식 도형)로 사물 · 인물 · 풍경 · 캐릭터 · 도구를 그리지 않는다.**
- 그림이 필요하면 **사용자에게 이미지를 요청**한다. 요청에는 ① 무엇(장면 · 사물) ② 쓰는 자리(표지 배경 · 사례 사진 · 오려 낸 사물) ③ 크기 · 비율 ④ 배경(투명 · 단색 · 사진) ⑤ 분위기 계열을 적는다.
- 사진은 AI로 만든 것을 쓴다(권리 문제 없음).
- 데이터 도식(막대 · 도넛 · 선 · 표 · 진행 막대), 아이콘 세트(`icons/`), 괘선 · 화살표 같은 구조 선은 그림이 아니다. 가능하면 HTML/CSS로 만든다.

## 5. 외부 사례
- 공공기관 우수 자료 · 외부 실물 사례는 **구조만** 가져온다. 로고 · 디자인 · 문구를 옮기지 않고 가상 내용으로 새로 만든다. 출처는 설계 메모에 적는다.

## 6. 피할 것 (밤티)
대화에서 짚은 것을 모두 여기에 더한다. 지금까지 저장소 수정 이력에 남은 것:
1. SVG로 그린 그림(4장). 숨긴 장표: #16 · #42 · #45 · #46 · #60 · #116 · #117.
2. 사물에 장식 부품 덧붙이기 — 글자 열차에 바퀴 · 차대 · 전조등을 그려 넣음(와우 ⑥, "바퀴 없이 입체 글자 열차만"으로 고침).
3. 요란한 효과 — 화면을 채우는 불티 · 스크램블 대신 절제된 영화 타이틀 톤(와우 '팡! 터뜨리기').
4. 만화식 움직임 — 찌그러짐(스쿼시) · 조이는 박자 · 이중 상(#109에서 제거).
5. 뭉개진 그림 · 글자 — 확대해 깨진 획(#108에서 복원).
6. 코드로 그린 지도 · 노선도 — 사진으로 바꿈(#102).
7. 재질 질감을 덱에 그대로 — 나무 · 유리 · 광택 플라스틱 · 도미노 · 종이 병풍 질감(#8 · #21 · #36 · #40 · #43 · #44의 '덱 제외 요소').
8. 뜻을 뒤집는 은유 — 자물쇠 = "모두 맞아야 열린다"(#42).
9. 깨진 한글 · 틀린 영어 · 빈칸으로 남은 날짜 · 장소(#64 · #67 · #104).

## 7. 숨기기
- 기준에 걸리는 장표는 지우지 않고 `data/rounds.json`에 `"hidden": true` · `"hide_reason"`을 적는다. 갤러리 목록에서 빠지고, 맨 아래 '숨긴 장표 보기'에서만 보인다.

## 8. 루틴
새 장표를 자동으로 만드는 루틴은 **모두 꺼 두었다**(2026-11-13). 갤러리는 지금 모으고 정리하는 단계다.
`docs/routine.md` · `scripts/variant.py`는 꺼 둔 루틴의 절차와 도구다. 다시 켤 때 고쳐 쓴다.
