# 제작 기준

새 장표 · 키트 · 덱을 만들 때 이 문서를 먼저 따른다. 대화에서 "이거 안 돼", "이거 밤티야"라고 짚은 것은 **6. 피할 것**에 계속 더한다.

## 1. 무엇을 만드나
- **발표 자료**다. 계획안(결재 문서)은 한글 문서로 따로 나가므로 이 갤러리의 대상이 아니다.
- 주된 자리는 **사업 성과 공유회**(중심)와 **사업 설명회**. 청중 앞 큰 화면에서 넘기며 말한다.
- 그래서 **움직임은 장점**이다. PPT 이식 · 흑백 인쇄 · 결재 양식은 기준이 아니다.
- 일정 · 예산 장표는 설명회의 '주요 일정' 정도만 필요하다.

## 2. 덱의 흐름
### 성과 공유회 (중심)
| 자리 | 하는 일 | 대표 정형 장표 |
|---|---|---|
| 여는 장 | 사업 이름 · 기관 · 날짜 | 표지 |
| 사업 개요 | 왜 · 누구에게 · 무엇을 했나 한 장 | 사업 개요, 추진 체계 |
| 추진 경과 | 언제 무엇을 했나 | 추진 경과 |
| 핵심 성과 | 숫자로 본 결과 | 핵심 성과, 목표 대비 달성, 전년 대비 · 비교, 추이, 구성비, 참여 분포 |
| 우수 사례 | 현장의 얼굴과 목소리 | 우수 사례, 참여자 목소리 |
| 변화 · 만족도 | 무엇이 달라졌나 | 만족도, 전후 비교 |
| 시사점 | 잘된 점 · 막힌 점 · 고칠 점 | 시사점 · 과제 |
| 향후 계획 | 다음 해에 무엇을 | 향후 계획 |
| 맺는 장 | 감사 · 문의 | 마무리 |

### 사업 설명회
| 자리 | 대표 정형 장표 |
|---|---|
| 사업 소개 | 사업 개요 |
| 지원 내용 | 요약표 |
| 신청 자격 · 절차 | 단계 · 절차 |
| 주요 일정 | 추진 경과(앞으로의 일정) |
| 유의사항 · 질문 | 자주 묻는 질문 |
| 문의 | 마무리 |

## 3. 정형 장표 유형 (갤러리 '무엇을 보여 주나')
성과 공유회 흐름 순서. 기존 장표의 `info_type`은 오른쪽처럼 옮겨 센다(새 장표는 `kind`에 바로 적는다).

| 정형 유형(`kind`) | 무엇 | 기존 `info_type` |
|---|---|---|
| 사업 개요 | 목적 · 대상 · 기간 · 규모 한 장, 비전 체계 | 배경·목적, 비전 체계도 |
| 추진 체계 | 누가 무엇을 맡았나 | 조직·체계 |
| 추진 경과 | 시간 순 연혁 · 일정 | 일정 |
| 주요 추진 내용 | 과제 · 프로그램 묶음 | 분류·유목화 |
| 핵심 성과 | 큰 숫자 3~4개 | 핵심 수치 |
| 목표 대비 달성 | 목표선과 실적 | — |
| 전년 대비 · 비교 | 올해 대 작년, 집단 간 비교 · 순위 | 비교·순위 |
| 추이 | 여러 해의 변화 | 추이 |
| 구성비 | 전체 중 몫 | 구성비 |
| 참여 분포 | 지역 · 학교 분포 | 지도·분포 |
| 우수 사례 | 사진 + 한 줄 성과 | — |
| 참여자 목소리 | 인용 · 후기 | — |
| 만족도 | 설문 결과 | — |
| 전후 비교 | 사업 전 · 후 | — |
| 시사점 · 과제 | 막힌 곳 → 고칠 방법 | 현안→해결방안 |
| 향후 계획 | 다음 단계 로드맵 | — |
| 단계 · 절차 | 신청 · 운영 절차 | 흐름·절차 |
| 요약표 | 지원 내용 · 항목 표 | 표·목록 |
| 자주 묻는 질문 | 질문 · 답 | — |

## 4. 그림
- **SVG(또는 CSS · 캔버스로 흉내 낸 SVG식 도형)로 사물 · 인물 · 풍경 · 캐릭터 · 도구를 그리지 않는다.**
- 그림이 필요하면 **사용자에게 이미지를 요청**한다. 요청에는 ① 무엇(장면 · 사물) ② 쓰는 자리(표지 배경 · 사례 사진 · 오려 낸 사물) ③ 크기 · 비율 ④ 배경(투명 · 단색 · 사진) ⑤ 분위기 계열을 적는다.
- 사진은 AI로 만든 것을 쓴다(권리 문제 없음).
- 데이터 도식(막대 · 도넛 · 선 · 표 · 진행 막대), 아이콘 세트(`icons/`), 괘선 · 화살표 같은 구조 선은 그림이 아니다. 가능하면 HTML/CSS로 만든다.

## 5. 외부 사례
- 공공기관 우수 자료 · 외부 실물 사례는 **구조만** 가져온다. 로고 · 디자인 · 문구를 옮기지 않고 가상 내용으로 새로 만든다. 출처는 설계 메모에 적는다.

## 6. 피할 것 (밤티)
대화에서 짚은 것을 모두 여기에 더한다. 지금까지 저장소 수정 이력에 남은 것:
1. SVG로 그린 그림(4장). 숨긴 장표: #16 · #42 · #45 · #46 · #60 · #116 · #117.
2. 사물에 장식 부품 덧붙이기 — 글자 열차에 바퀴 · 차대 · 전조등을 그려 넣음(와우 ⑥, "바퀴 없이 입체 글자 열차만"으로 고침).
3. 요란한 효과 — 화면을 채우는 불티 · 스크램블 대신 절제된 영화 타이틀 톤(와우 '팡! 터뜨리기').
4. 만화식 움직임 — 찌그러짐(스쿼시) · 조이는 박자 · 이중 상(#109에서 제거).
5. 뭉개진 그림 · 글자 — 확대해 깨진 획(#108에서 복원).
6. 코드로 그린 지도 · 노선도 — 사진으로 바꿈(#102).
7. 재질 질감을 덱에 그대로 — 나무 · 유리 · 광택 플라스틱 · 도미노 · 종이 병풍 질감(#8 · #21 · #36 · #40 · #43 · #44의 '덱 제외 요소').
8. 뜻을 뒤집는 은유 — 자물쇠 = "모두 맞아야 열린다"(#42).
9. 깨진 한글 · 틀린 영어 · 빈칸으로 남은 날짜 · 장소(#64 · #67 · #104).

## 7. 숨기기
- 기준에 걸리는 장표는 지우지 않고 `data/rounds.json`에 `"hidden": true` · `"hide_reason"`을 적는다. 갤러리 목록에서 빠지고, 맨 아래 '숨긴 장표 보기'에서만 보인다.

## 8. 루틴 프롬프트에 붙일 규칙
새 회차를 만드는 claude.ai 루틴의 프롬프트에 아래를 그대로 붙인다.

```text
[제작 기준 — docs/criteria.md 요약]
- 대상: 사업 성과 공유회(중심) · 사업 설명회 발표 자료. 움직임은 장점. 결재 · PPT 이식은 기준 아님.
- 본문 장표는 정형 유형(kind) 하나를 정해 만든다: 사업 개요 · 추진 체계 · 추진 경과 · 주요 추진 내용 · 핵심 성과 · 목표 대비 달성 · 전년 대비·비교 · 추이 · 구성비 · 참여 분포 · 우수 사례 · 참여자 목소리 · 만족도 · 전후 비교 · 시사점·과제 · 향후 계획 · 단계·절차 · 요약표 · 자주 묻는 질문. rounds.json 에 "kind" 로 적는다.
- SVG(또는 CSS · 캔버스로 흉내 낸 도형)로 사물 · 인물 · 풍경 · 캐릭터를 그리지 않는다. 그림이 필요하면 만들지 말고 사용자에게 이미지를 요청한다(무엇 · 자리 · 크기 · 배경 · 계열).
- 피할 것: 장식 부품 덧붙이기, 요란한 효과, 찌그러짐 · 조이는 박자 같은 만화식 움직임, 뭉개진 그림, 코드로 그린 지도, 재질 질감, 뜻을 뒤집는 은유, 깨진 한글 · 틀린 영어 · 빈칸.
- 검사(scripts/check.js, ingest.py 가 실패시킴): 움직이는 장표는 prefers-reduced-motion 처리, 움직임 줄이기에서 무한 반복 없음, 인쇄·홍보물은 @media print(장면이 아니라 실제 인쇄물), 덱 장표는 16:9 무대 안에 넘침 없음.
```
