원본 그림은 그대로 두고 버튼·화면 글자·떨어지는 상자(원본에서 오려 냄)·장표만 얹었다. 화면이 "B1 설문 분석 나오는 중…"으로 켜지고, 상자가 흔들리다 떨어져 꺼내는 곳에 눕는다. 장표는 ① 무엇을 해 주나(기능 셋 + 전·후 수치) ② 이렇게 씁니다(3단계 + 받는 곳). 본 도구 버튼에는 노란 점이 남는다. 직접 눌러 보세요. 가상 예시

01고친 곳

꼬리말을 "다음 행동"으로

"도구명과 구성은 콘셉트 설명을 위한 예시입니다"는 보는 사람에게 쓸모가 없다. 같은 자리·같은 서체 톤으로 받는 곳과 문의를 넣었다. 포스터에서 가장 작은 줄이 가장 실용적인 줄이어야 한다.

손대지 않은 것제목의 청록 판 어긋남, 망점·종이 질감, 진열 상자 여섯 개의 재질 차이(종이 상자·통조림·지퍼 봉지·탁상 달력·블리스터)는 손대지 않았다. 이 포스터의 힘은 거기서 나온다.

02가져갈 장치

01

누르면 다음 장으로

포스터가 곧 메뉴판. 버튼 = 목차, 떨어지는 상자 = 장 넘김, 꺼내는 곳 = 장표로 들어가는 문. 끝나면 메뉴로 돌아온다.

연수 과정 소개, 지원 사업 안내 키오스크, 발표 첫 장의 목차

02

번호로 동선 만들기

진열칸 A1 → 이름표 A1 → 버튼 A1. 같은 기호가 세 번 나오면 눈이 저절로 따라간다.

연수 과정 메뉴판, 부스 배치도, 지원 사업 안내

03

3도 + 판 어긋남

주홍·짙은 녹색·노랑. 제목 한 곳만 청록 판을 2~3px 어긋나게.

어긋남은 한 곳만. 작은 글자에는 금지

03이렇게 다시 뽑기

04인쇄 전에

  • 원본 비율이 16:9라 화면·배너용으로 가장 좋다. A3 가로(1.414:1)로 뽑으면 위아래에 4% 여백이 생긴다 — 바탕 크림색으로 채우면 자연스럽다.
  • 그림은 1672px 폭(가로 A3에서 약 100dpi). 실제 인쇄용은 같은 프롬프트로 4K 이상 다시 뽑거나 업스케일 후 사용.
  • 주홍(#E8462A 근처)은 CMYK로 탁해진다. 교정쇄를 꼭 보고, 가능하면 별색 상담.

06HTML 코드

  1. 코드를 빈 .html 파일로 저장하면 포스터 한 장이 그대로 열립니다(바탕 그림·글꼴 포함, 인터넷 연결 없이도).
  2. 문구는 마크업의 글자를, 위치·크기는 u 단위(지면 폭 기준) 숫자를 바꾸면 됩니다.
  3. 인쇄: 크롬에서 열고 인쇄 → PDF로 저장, 여백 없음, 배경 그래픽 켜기.
  4. AI 채팅에는 링크 대신 이 코드를 붙여 넣으세요.
