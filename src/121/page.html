원문 → 유목화줄글 한 문단을 짝 넷 + 띠 하나로

왼쪽은 정리 전 계획안 문단, 오른쪽은 묶은 방법입니다. 같은 번호가 장표의 같은 줄(①~④)과 아래 띠(⑤)입니다.

정리 전 원문 (가상)

2026년 4월 특수교육 실태조사 결과 관내 일반학교 통합학급에 배치된 특수교육대상학생은 2,184명이다. ①특수교육실무사 1명이 평균 7.8명을 지원하고 있어 이동·급식 시간에 지원 공백이 생긴다는 의견이 많다. 이에 ①실무사 120명을 증원하여 2027년 3월 배치하고 1명당 5.5명으로 낮춘다. ②통합학급 담임교사의 특수교육 연수 이수율은 38%에 그쳐 개별화교육 협의 참여가 저조하다. ②담임 직무연수 15시간을 의무화하여 2027년 말까지 이수율 80%를 달성한다. ③도전행동으로 인한 위기 지원 요청은 연 412건이며 외부 전문가 지원까지 평균 21일이 걸린다. ③2027년 9월 권역별 행동지원센터 4곳을 열어 요청 후 7일 이내 현장 지원한다. ④승강기가 없는 학교가 46교로 지체장애 학생의 교실 이동이 제한된다. ④2028년까지 30교에 승강기를 설치하고, 나머지 16교는 경사로와 저층 교실 배치로 대신한다. ⑤소요 예산은 2027~2029년 총 214억 원이며, 성과는 매년 4월 실태조사로 측정하고 특수교육과가 총괄한다.

묶은 방법

  1. ①인력현안 “1명이 7.8명” → 현재값 7.8명 / 방안 “120명 증원·3월 배치” → 목표값 5.5명
  2. ②전문성현안 “이수율 38%” → 38% / 방안 “15시간 의무화·2027년 말” → 80%
  3. ③행동지원현안 “평균 21일, 연 412건” → 21일 / 방안 “센터 4곳·9월 개소” → 7일 이내
  4. ④접근성현안 “승강기 없는 46교” → 46교 / 방안 “30교 설치 + 16교 대체” → 30교(남은 16교는 근거 줄에)
  5. ⑤예산·측정네 줄 모두에 걸리는 총사업비·측정·담당은 표 밖 띠 하나로

①~④ 줄 현안과 방안을 1:1로 짝지어 같은 높이에 놓습니다. 화살표는 “이 현안을 이 방안으로”라는 대응 하나만 뜻합니다.

줄 순서 원문 순서(사람 → 역량 → 위기 → 시설) 그대로. 위계가 아니라 나열이라 줄 색은 모두 같습니다.

뺀 것 없음 대상 학생 2,184명과 조사 시점은 제목 아래 기준 줄로 옮겼습니다.

구조 설명

정보 구조

현안과 해결방안을 두 열로 나누고, 같은 주제의 현안·방안을 같은 줄에 놓습니다. 두 칸은 똑같이 수치(160) + 한 줄 + 근거·시기로 짜여 있어 가로로 읽으면 “7.8명 → 5.5명”처럼 현재값과 목표값이 같은 기준선에서 비교되고, 세로로 읽으면 현안 목록과 방안 목록이 됩니다. 해결방안 열이 결론이므로 열 머리 밑줄과 칸 바탕을 진한 쪽(c1·c5)으로, 현안 열은 옅은 쪽(c4·흰 바탕)으로 둡니다.

가져갈 장치 · 응용 예

  • 칸 문법 통일: 왼쪽·오른쪽 칸이 같은 순서(숫자 → 한 줄 → 근거)라서 숫자끼리, 문장끼리 같은 높이에 맞습니다. 현재값과 목표값이 생기는 계획안이면 지표 표를 따로 만들 필요가 없습니다.
  • 열의 무게는 농담으로: 결론 쪽 열만 c5 바탕을 깔아 시선이 오른쪽에서 끝나게 합니다.
  • 응용: 학교폭력 사안 처리 지연 → 개선(처리 기간 일수) / 늘봄 대기 학생 → 프로그램 확충(명) / 노후 교실 → 그린스마트 개축(교)

이 틀을 변주하는 법

  • 강조 위치 하나만: 결론이 “모두 고르게”면 제목 단어에, “이 하나가 급하다”면 그 줄에 강조색을 둡니다. 둘 다 쓰지 않습니다(변주 1).
  • 항목 이름 자리: 비교가 대칭(전·후, 우리·타 시도)이면 항목 이름을 가운데로 옮겨 좌우가 마주 보게 합니다. 이때 화살표는 뺍니다(변주 2).
  • 줄 수: 3~5줄까지. 6줄 이상이면 근거 줄을 빼고 수치 + 한 줄만, 그래도 넘치면 표 + 요약 상자 틀로 바꿉니다.
