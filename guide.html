이용 방법

발표 내용을 먼저 정하고, 스타일을 고른 다음, AI에게 적용을 요청합니다.

1. 스타일을 직접 고를 때

  1. 전체 스타일에서 마음에 드는 스타일의 전체 장표 보기를 누릅니다.
  2. 10장 예시를 넘겨 보고, 이 스타일 적용 요청문 복사를 누릅니다.
  3. AI 대화창에 발표 내용(문서)과 함께 붙여 넣습니다. AI가 장별 구성안을 먼저 보여 주면 확인하고 만들게 합니다.
  4. 받은 .html 파일을 열어 → 키로 넘겨 보고, 숫자를 원문과 대조합니다.

2. 고르는 것도 AI에게 맡길 때

아래 요청문을 복사해 발표 내용과 함께 붙여 넣습니다.

제가 올린 발표 내용에 어울리는 디자인을 아래 갤러리에서 골라 적용해 주세요.

1. 목록 읽기: https://szxv7704-dot.github.io/design-reference-gallery/catalog.md
2. 제 발표의 내용과 자리(누구에게, 몇 분)를 보고 '검증된 세트' 중에서 스타일 하나를 고르고, 이유를 한 줄로 말해 주세요.
3. 고른 스타일의 적용 안내(목록에 적힌 주소)를 읽고, 10장 안팎의 발표 HTML 파일 하나로 만들어 주세요.

지킬 것:
- 자료를 실제로 열어 읽은 뒤에 적용해 주세요. 주소를 열 수 없으면 읽은 척하지 말고 열 수 없다고 말해 주세요.
- 먼저 장마다 "전하려는 것 · 고른 구성 · 제목"을 표로 보여 주고, 제가 확인하면 만들어 주세요.
- 스타일은 하나만 쓰고, 장마다 내용에 맞는 구성을 고릅니다. 한 장에 구성 하나.
- 예시에 들어 있는 기관명 · 수치 · 사례는 가상입니다. 제 발표에 가져오지 마세요. 제가 주지 않은 숫자를 지어내지 마세요.
- 내용이 많으면 글자를 줄이지 말고 장을 나눠 주세요. 제 핵심 내용을 임의로 빼지 마세요.

알아 둘 점

  • 완성 상태: 검증된 세트(10장 예시 · 다른 주제 시험 · 넘침 검사 통과) 5개 · 확장 중 3개 · 표지에서 넓힌 덱 27벌(표지의 색 · 글꼴을 입힌 10장).
  • AI가 만든 발표는 열 때 인터넷이 필요합니다(글꼴 · 스타일을 이 사이트에서 불러옵니다). 내려받은 예시 발표는 인터넷 없이 열립니다.
  • 개인정보(학생 이름 · 사진)는 AI에게 넣지 마세요.
  • AI가 주소를 열지 못하는 환경이면, 스타일 화면의 "파일과 자료"에서 적용 안내(.md)를 내려받아 첨부하세요.
