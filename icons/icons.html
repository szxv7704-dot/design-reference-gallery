교육행정 아이콘 세트

본문 장표에서 묶음의 성격을 글보다 먼저 알려 주는 아이콘입니다. 모양·선 굵기·끝처리를 한 규격으로 맞췄고, 색은 장표의 --ds-* 변수를 따라 계열을 바꾸면 같이 바뀝니다. 모든 아이콘은 SVG로 페이지 안에 들어가 인터넷이 없어도 보입니다.

아이콘 0개묶음 0개격자 24×24선 1.75 · 둥근 끝원본 Tabler Icons(MIT)

쓰는 규칙 RULES

한 묶음에 하나, 묶음 머리에

카드·단계·칸의 머리말 옆에 하나만 둡니다. 목록 항목마다 붙이지 않습니다.

✕ 글머리표 자리마다 아이콘

뜻이 맞을 때만

머리말 단어와 아이콘 이름이 맞아야 합니다(예산 → 예산, 점검 → 점검표). 맞는 것이 없으면 넣지 않습니다.

✕ 빈자리를 채우려고 아무 아이콘

늘 글자와 함께

아이콘만으로 뜻을 전하지 않습니다. 인쇄·흑백에서도 머리말 글자로 읽혀야 합니다.

색 하나, 배지 하나

아이콘 색은 --ds-accent 또는 --ds-c1 한 가지. 배지 모양은 한 덱 전체에서 한 종류만 씁니다.

크기는 두 단계

1600×900 장표 기준 묶음 머리 40~56px, 목록·수치 옆 24~28px. 한 장표 안에서 두 단계를 넘지 않습니다.

세트 밖 아이콘 금지

이모지·다른 모양의 아이콘을 섞지 않습니다. 필요한 아이콘이 없으면 같은 규격으로 세트에 더합니다.

아이콘 목록 누르면 SVG 코드 복사

선 굵기

HTML로 가져다 쓰기 CODE

  1. 아래 공통 CSS를 장표 CSS 맨 위에 한 번 붙입니다.
  2. 목록에서 아이콘을 누르면 <svg class="ds-ic"…> 코드가 복사됩니다. 배지가 필요하면 <span class="ds-badge is-round"> 안에 넣습니다.
  3. 크기는 배지의 --s, 선만 쓸 때는 font-size로 정합니다. 색은 --ds-accent를 바꾸면 따라옵니다.
  4. AI 채팅에는 링크 대신 이 코드와 아이콘 코드를 붙여 넣으세요.

  


  

    
PPT로 옮기기 POWERPOINT

    
    
      
  1. 목록에서 아이콘을 눌러 코드를 복사하고, 메모장에 붙여 이름.svg로 저장합니다(인코딩 UTF-8).
    2. 
      
  2. PowerPoint [삽입] → [그림] → [이 디바이스]로 SVG를 넣습니다. 오른쪽 클릭 → [도형으로 변환]하면 선 색·굵기를 PPT에서 바꿀 수 있습니다.
    3. 
      
  3. 16:9(33.867×19.05cm) 기준 묶음 머리 아이콘은 1.0~1.2cm, 목록 옆은 0.5~0.6cm. 선 굵기는 1.0~1.25pt로 모든 아이콘을 같게 둡니다.
    4. 
      
  4. 배지: 원·사각은 [도형] 위에 아이콘을 가운데 맞춤 후 그룹. 평행사변형은 [도형] → 평행 사변형, 조절점으로 기울기 18%.
    5. 
      
  5. PPT 자체 [아이콘] 메뉴의 아이콘과 섞지 않습니다(선 굵기·모양이 달라 덱이 흐트러집니다).
    6.
