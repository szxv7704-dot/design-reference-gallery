### #82 놀이 블록 키트
- 쓰임: 목차·간지 · 모션
- 분위기: C 경쾌한 놀이 오브젝트
- 가져갈 장치: 섹션 수 = 블록 수, 층 순서 = 목차 순서: 목차(다 쌓인 탑) → 간지(그 층이 놓임, 남은 층은 점선) → 마무리(깃발) 세 장이 한 물체의 진행으로 이어짐
- 설명: C 경쾌한 놀이 오브젝트 계열(#7·24·29·39·59)의 목차·섹션 간지·마무리 3장과 계열 값 카드. 섹션 다섯 개 = 장난감 블록 다섯 층: 목차는 다 쌓인 탑과 층 색 블록 머리 목록, 간지는 그 섹션 블록이 위에서 놓이고(0.65초) 남은 층은 점선, 마무리는 깃발을 꽂은 탑으로 표지 #7과 수미상관.
- 겉모습: 밝은 하늘빛 흰 바탕 + canvas 축측 2×4 장난감 블록(윗면 광택, 돌기 초승달 반사, 접촉 그림자, 바닥 번짐), Black Han Sans 제목·Fredoka 둥근 숫자, 3px 먹선 머리말 띠, 둥근 흰 문의처 카드

- 글꼴: Black Han Sans(제목) + IBM Plex Sans KR 400/600/700(본문) + Fredoka 600(숫자) / 대체 Gmarket Sans·맑은 고딕·Arial Rounded MT Bold

### #40 도미노 일정표
- 쓰임: 본문 · 모양 일정 · 자리 일정 · 예산 · 모션
- 분위기: B · C 에 갈아 끼움
- 가져갈 장치: 도미노 1개 = 1개월, 넘어짐 = 완료: 기간을 개수로 세고, 갈라짐·합류로 병행 과제와 공동 목표를 한 장에
- 설명: 추진 일정을 한 달 1개 도미노로 세워, 앞 절차가 넘어져야 다음이 넘어지는 연쇄로 선후 관계를 보여 준다. 1월 기본계획에서 시설·운영 두 줄로 갈라졌다가 이듬해 4월 재개관 도미노에서 합류하고, 병목인 실시설계는 주황으로 강조한다.

### #44 분자 결합 추진체계
- 쓰임: 본문 · 모양 체계 · 자리 추진 체계 · 모션
- 분위기: B · C 에 갈아 끼움
- 가져갈 장치: 결합 차수 = 협업 강도: 이중·단일 결합 막대로 상시 협업과 요청 시 연계를 구분하고, 원자가 핵에 붙는 순서로 조직이 짜이는 과정을 보여 주기
- 설명: 추진체계를 공 막대 분자 모형으로 바꿔, 통합창구(핵)에 다섯 기관 원자가 던져져 결합하는 순서로 조직이 짜이는 과정을 보여 준다. 이중 결합 = 상시 협업(창구 상주), 단일 결합 = 요청 시 연계이고, 마지막에 기업 원자가 창구에만 붙은 뒤 신청 신호가 필요한 기관까지 흐른다.
- 겉모습: 밝은 실험대 바탕 canvas 공 막대 모형: 좌상단 광원 광택 플라스틱 구(하이라이트·바닥 반사광), 폭 방향 그라데이션 원통 막대, 이중·단일 결합, 흐린 바닥 그림자, 결합 직후 반동
- 색: #F4F7F8 #14283F #24466E #F08A24 #2E9E6A #2F7BE0 #E8562F
- 글꼴: Gothic A1 (대체: Apple SD Gothic Neo, 맑은 고딕)
- 코드: https://szxv7704-dot.github.io/design-reference-gallery/light/44.html · 원본: https://szxv7704-dot.github.io/design-reference-gallery/refs/44.html

### #63 업무도구 자판기
- 쓰임: 인쇄·홍보물 · 인터랙션
- 분위기: C 경쾌한 놀이 오브젝트
- 가져갈 장치: 누르면 다음 장으로 — 포스터가 곧 메뉴판. 버튼 = 목차, 떨어지는 상자 = 장 넘김, 꺼내는 곳 = 장표로 들어가는 문.
- 설명: 누르는 포스터: 버튼(A1~B3)을 누르면 그 업무도구가 떨어져 꺼내는 곳으로 나오고, 도구 안내 장표 두 장을 거쳐 자판기로 돌아온다.
- 겉모습: 고르는 일을 자판기로. 진열칸·이름표·버튼에 같은 번호를 세 번 반복해, 설명 없이 "골라 쓴다"가 읽히는 레트로 3도 인쇄 포스터.
- 색: #EAE6D9 #0A3327 #3B5E4D #DE4D25 #919684 #E5D840
- 코드: https://szxv7704-dot.github.io/design-reference-gallery/light/63.html · 원본: https://szxv7704-dot.github.io/design-reference-gallery/refs/63.html
