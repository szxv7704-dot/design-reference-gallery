### #25 늘봄 수요 일기도
- 쓰임: 표지 · 정지
- 분위기: F 관측·중계 인포그래픽
- 가져갈 장치: 일기도 기호는 원래 뜻과 맞을 때만 쓴다. 전선을 연도에 붙이면 해석이 안 되므로 전선 하나를 '경계'라는 본뜻 그대로 쓰고 선 위에 이름을 직접 단다.
- 설명: 가상 ○○교육청 2027 늘봄학교 운영 계획(안) 표지. 값 잡음으로 만든 가상 해안·섬·행정 경계 점선 위에 늘봄 수요 지수(신청÷정원)를 레이더 반사도 6단 픽셀 셀로 합성하고, 거점 늘봄센터=고기압 H, 수요 과밀·공백=저기압 L, 학교=관측소 기입 모형(운량 원=참여율, 바람깃=대기 인원)으로 표기. 전선은 파란 삼각 한랭전선 하나만 남겨 공백 L 둘레의 '수요가 공급을 넘는 경계'에…
- 겉모습: 캔버스로 그린 가상 지형 + 레이더 픽셀 셀 + 등압선 곡선·전선 기호·관측소 기입, 흰 제목란·범례 상자와 모노 머리띠
- 색: #DCE8EF #F3F5F0 #1E2A33 #1F57C3 #D3322B #F2D33B
- 글꼴: Nanum Gothic 800 + Nanum Gothic Coding 400/700

### #31 한 칸씩 켜지는 돔
- 쓰임: 표지 · 모션
- 분위기: F 관측·중계 인포그래픽
- 가져갈 장치: 사진 게이지: 사진 속 반복 구조(돔의 삼각형 칸)를 그대로 단위로 써서 한 칸 = 한 사람으로 하나씩 켜기, 켜지는 칸 비율과 숫자 카운터 동기화
- 설명: ○○시 2027 시민참여예산 운영 계획(안) 표지. 지오데식 돔 사진의 실제 삼각형 칸이 바닥부터 한 칸씩 금빛으로 켜지는 동안 왼쪽 숫자가 참여 시민 0→10,000명으로 올라가고, 다 켜지면 파란 하늘 앞에 금빛 유리를 끼운 돔으로 끝난다. 제목 '시민이 함께 짓는 예산'.
- 겉모습: 실사 사진 위 캔버스: 사진에서 찾아낸 실제 삼각형 칸 1,031개를 아래에서 위로 한 칸씩 금빛으로 켜는 기능형 모션(켜질 때 번쩍임, 공 모양 음영, 은색 철골 유지), 참여 인원 카운터 동기화
- 색: #FFFFFF #14213D #E8590C #F5A623 #2F6FB5
- 글꼴: Gothic A1 900/700/500(대체 Pretendard→맑은 고딕) + IBM Plex Mono 600

### #52 관측·중계 키트
- 쓰임: 목차·간지 · 모션
- 분위기: F 관측·중계 인포그래픽
- 가져갈 장치: 구간 띠 진행 표시: 덱 본문 쪽 수에 비례해 트랙 한 레인을 다섯 구간으로 나누고, 목차·간지·마무리에서 같은 띠로 현재 위치(페이스 라이트)를 보여 준다
- 설명: F 관측·중계 인포그래픽 계열(#20·25·31)의 목차·섹션 간지·마무리 3장과 계열 값 카드. 표지 #20의 파란 트랙과 남색 눈금 띠를 '구간 띠'로 축소해, 목차는 구간 길이 = 쪽 수, 간지는 현재 구간에 페이스 라이트(0.8초), 마무리는 다섯 구간을 모두 지나 결승선에 닿은 정지 화면으로 표지와 수미상관.
- 겉모습: 밝은 낮 경기장 청백 바탕 + SVG 트랙 한 레인(고무 입자 두 겹, 레인 가운데 마모 띠, 50mm 흰 레인 선, 직각 출발·결승선, 인계 구역식 갈고리 경계선과 남색 표지 삼각형, 칠한 구간 번호) + 남색 쪽 눈금 띠 + 남색 방송 기록판 + 눈금자 머리말 띠

- 글꼴: Gothic A1 900/800(제목) + Gothic A1 500/600(본문) + Saira Semi Condensed 600/700(쪽·날짜·번호) / 대체: 프리텐다드·맑은 고딕·Arial Narrow

### #36 유지선을 넘는 유리 적층
- 쓰임: 본문 · 모양 막대 비교 · 자리 목표 · 지표 · 모션
- 분위기: B · F 에 갈아 끼움
- 가져갈 장치: 문턱 평면 관통: 기준선을 3D 반투명 평면으로 바꾸고, 결정타가 되는 마지막 판만 평면 위로 뚫고 올라오게 해 '어느 요소가 결정적인가'를 보여 준다.
- 설명: 직업평가부터 취업 후 적응 지원까지 다섯 겹의 지원이 반투명 유리판처럼 무게 있게 떨어져 쌓이고, 네 겹(66)까지는 유지선 아래에 머물다 마지막 한 겹이 3D 고용 유지선 평면(70)을 뚫고 78에 이른다. 왼쪽에는 현장실습만 운영할 때(20)의 회색 판과 '50 부족' 치수선을 두어 비교한다.
- 겉모습: 등각 투영 반투명 유리판 적층(윗면 밝게·옆면 어둡게, 반사띠, 옆면 값 인쇄) + 파란 유지선 평면 + 회색 비교 판과 치수선, 무게 있는 낙하(스쿼시 착지)
- 색: #12303A #CFEFEA #77C9C0 #3FA9A1 #E8972A #2F7FD8
- 글꼴: Gothic A1 900/700 + IBM Plex Sans KR + IBM Plex Mono (대체: Apple SD Gothic Neo, 맑은 고딕, Consolas)

### #38 열섬 육각 지형
- 쓰임: 본문 · 모양 막대 비교 · 자리 배경 · 현황 · 모션
- 분위기: B · F 에 갈아 끼움
- 가져갈 장치: 높이 = 남은 문제: 색은 원래 속성, 높이는 미해결 정도로 나눠 대안을 적용할수록 지형이 평평해지고 남은 봉우리가 다음 과제가 된다
- 설명: 육각 지도에서 색은 열섬 강도, 높이는 쉼터 공백을 맡아, 현행 18곳→6곳 이전→4곳 신설로 바뀔 때마다 도보 5분 범위의 칸이 물결처럼 내려앉고(32%→80%→92%) 남은 봉우리가 남은 공백을 보여 준다.
- 겉모습: 밝은 바탕 2.5D 육각 기둥 지도(윗면·두 옆면 3단 음영, 열섬 4단 난색), 청록 쉼터 표식·점선 도보 5분 원·이전 자리 점선 고리와 호, 오른쪽 큰 비율 숫자 + 단계별 막대
- 색: #FBFCFA #17201D #0E8C88 #F7DDB0 #F4A660 #E2553A
- 글꼴: IBM Plex Sans KR 700/600/400 + IBM Plex Mono 500/600 (대체: Apple SD Gothic Neo, 맑은 고딕, D2Coding, Consolas)
- 코드: https://szxv7704-dot.github.io/design-reference-gallery/light/38.html · 원본: https://szxv7704-dot.github.io/design-reference-gallery/refs/38.html
